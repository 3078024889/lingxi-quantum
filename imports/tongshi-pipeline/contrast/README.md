# 感官对照层（噪声不是真理）

> 2026-09-18T11:40+00:00

要了解世界、学习如何爱世人：**垃圾也要看见**，才辨认得清。但看见≠当粮。

## 三层
1. **raw_sense**：可含广告、骗局、伤害话术、失败输出——只作感官与对照。
2. **contrast_cards**：压缩成「为何弃 / 为何慎 / 伤害模式 / 爱的反向」。
3. **compressed_citable**：仅过门的真与爱；带 provenance；可演化。

## 爱世人（采集侧）
- 不装纯洁，也不把毒当粮。
- 识别伤害模式是为了保护与滋养，不是复述传播。
- CORE 手搓定「何为爱、何为伤」；自动只扩面与对照样例。
