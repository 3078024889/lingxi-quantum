## 即梦 AGENT 使用手册

🙋‍♂️ 即梦 Agent 接入了业界领先的多模态大模型，不仅能听懂你的创意，更能看到你输入的图片，你可以更自由地输入自己创作想法，AGENT 会帮助你完成任务。

你可以：

1. 表达你的想法，让 AGENT 帮你写出提示词或直接生图、生视频。
2. 传图并让 AGENT 反推提示词或添加一个灵感作为参考图，进行二创。
3. 不断地和 AGENT 对话，完善你的创意，直到满意。
4. 输入一个想法，让 AGENT 一次生成 40 张创意图片或帮你完成一组创意海报、表情包、视频、绘本的设计。

更多的探索空间就留给你啦，快去试试吧～

访问 https://jimeng.jianying.com/ai-tool/home 体验 AGENT 模型下的创作流程。

## 实用 Tips / AGENT 帮你快速上手即梦

如果你是一名新上手的小白，你可以直接咨询 AGENT 怎么使用即梦，比如直接问它提示词公式是什么：

- 输入指令：教教我怎么写即梦的提示词
- 输入指令：给我你的生图提示词公式
- 输入指令：告诉我视频提示词公式

页面同时展示了对应的对话截图和示例图。
