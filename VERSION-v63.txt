灵犀 LINGXI · v63（心声之雨修复 + 语料库版权清理 + 全新搜索框）

★ 在 v62 基础上的增量改动，直接上传这一个 v63 即可（累计包含 v49-v62 全部内容）。

【问题1修复：心声之雨的展开方向和光点分布】
- 上一版把文字气泡改成"朝屏幕外侧展开"，结果光点本来就贴着视口边缘，
  文字一展开就被裁掉、根本看不见——这次改回"朝屏幕内侧展开"，确保
  气泡出现在可视范围内。
- 光点现在恢复全宽度分布（不再只挤在两侧），整个背景都会动起来；
  但做了分区：两侧约18%宽度的光点，允许像以前一样自动轮播绽放文字；
  中间阅读列的光点，只有鼠标悬停或点击才会显示文字，不会自动弹出来
  打扰阅读。

【问题2：语料库版权清理（重要）】
检查 lib/voices.ts（首页/全站漂浮光点用的语料库）后发现，里面有大量
直接照搬灵性译著原文特有名词的内容，比如"造翼者""中央种族""主权性
积分态""魂线""哥白尼之音""六心之德""源之音""初始创造者""爱之建筑"
等主题，一共172行——这些是原作者/译者的原创译名，直接放在站上有实际
版权风险，这次全部删除了。
另外，"量子暂停呼吸""上升之心""直觉智能""心的重置"这几个技术名词，
在语料库文字内容里散落出现了很多次（不只是主题标签），这次统一改成
了跟插画故事一致的原创名称：
- 量子暂停呼吸/量子呼吸 → 量子息法
- 上升之心 → 升维心经
- 直觉智能 → 直觉丹道
- 心的重置 → 归零心诀
语料库从1055行清理到约876行，保留的都是"场域/共振/忆起/临在/校准"
这类通用灵性词汇，不再有指向单一译著的专属名词。

【问题3：全新搜索框】
在导航栏（桌面端+移动端）加了一个可搜索的框：
- 输入关键词（中英文都行），实时匹配62篇多维叙事的标题/简介，
  也能匹配站内几个核心页面（意识显化/探索梦境/修炼技术/多维叙事等）
- 点击结果直接跳转
- 框体本身做了独立设计：金色细边框，聚焦时边框和阴影会亮起来；
  点击框体时，会在点击的具体位置绽放一圈局部水波纹（这个水波纹只在
  框内出现，跟全站已有的点击水波纹是两套独立效果）

【验证方式（每次都做）】
1. npx tsc --noEmit → 通过
2. npx next build → 通过
3. 临时开 REVIEW_MODE=true 本地起服务，首页/列表页/修炼页/新故事页
   实测 200，并确认渲染出的 HTML 里包含搜索框的 class
4. 关闭 REVIEW_MODE，重新 build，确认 lib/reviewMode.ts 为 false 后打包
