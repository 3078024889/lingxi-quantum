灵犀 LINGXI · v102（视觉方向调整：从米白亮色系，改成暮光宇宙+玻璃质感+彩虹能量场）

★ 在 v101 基础上的改动，直接上传这一个 v102 即可（累计包含 v49-v101 全部内容）。

按你发的设计文档方向重做了配色——不是纯黑不是纯白，是深紫蓝的"暮光
宇宙"底色，配半透明玻璃质感的卡片，彩虹渐变用在按钮和品牌强调色上。

【具体改了什么】
1. **背景**：从单色米白，改成多层径向渐变——粉色/蓝色/金色三处光晕
   叠加在深紫蓝底色（#171526 → #25203b → #182b38）上，效果是星云
   感，不是纯色块
2. **卡片**：全部加上了 backdrop-blur-xl（玻璃质感），配合半透明
   白色背景（rgba(255,255,255,0.07)），像悬浮的玻璃板
3. **文字颜色**：标题用月光白（#F4EFFF），正文用淡紫（#C9C4E8）——
   这两个颜色，在深紫蓝背景上，对比度是足够的，不会出现"黑字配黑
   底"看不清的问题
4. **品牌渐变**：蓝→紫→金（#7CE7FF → #CFA8FF → #FFD98A），用在
   主按钮和呼吸光球上
5. **按钮**：改成渐变背景+深色文字+柔和光晕阴影（0 0 30px 的紫色
   光晕），像"进入场域"的感觉
6. **罗盘图与星盘**：背景从米白渐变改成深紫渐变，星点、文字、线条
   颜色都对应改成了亮色，保证在深色背景上清晰可见

技术细节：因为之前已经建立了一套 lm2- 前缀的独立配色token系统，这次
只需要改 tailwind.config.ts 里几个颜色的具体数值，不需要逐个文件
重新替换class名——所有已经用了 bg-lm2-bg / text-lm2-text 这些class
的地方，会自动跟着新配色走。

【重要：构建修复没有受影响】
上一版修的"createClient()位置"和"force-dynamic标记"这两个构建
bug修复，这次改动没有碰，专门重新测试了一次"完全不设置环境变量"的
极端场景，确认构建依然成功。

【验证方式（每次都做）】
1. npx tsc --noEmit → 通过
2. npx next build → 通过，且专门重新验证了"无环境变量"极端场景，
   确认上一版的构建修复没有被这次的样式改动破坏
3. REVIEW_MODE=true + 占位凭据本地起服务：
   - /life-map 页面实测 200，确认页面含"bg-lm2-nebula"星云背景
     class
