# Lingxi Source Corpus

This directory documents the private source-material ingestion process. Original files and extracted text are intentionally excluded from Git.

## Corpus Baseline

- 178 PDF files received.
- 174 unique PDFs after SHA-256 deduplication.
- 7,024 pages.
- Approximately 5.93 million extracted characters.
- 0 extraction errors.
- 0 documents below the 50% extractable-page threshold.
- 1 video retained as private source material and never executed.

Private paths:

- `research/source-materials/raw/`
- `research/source-materials/private-text/`

Both paths are ignored by Git. The private index stores source-relative paths, SHA-256 fingerprints, page counts, extraction coverage, and duplicate relationships.

## Publication Boundary

Original titles, named fictional systems, distinctive labels, and extended wording are not product vocabulary. Source material may inform mechanisms, safety principles, questions, and practices only after independent rewriting and editorial review.

No source text is copied directly into a paid report. Knowledge nodes must pass the translation protocol and the executable knowledge lint before release.
