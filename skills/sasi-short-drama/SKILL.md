# SASI Short Drama

Build an original, production-ready short-drama package.

## Workflow

1. Identify audience, genre, episode objective, opening hook, conflict escalation, emotional payoff, and closing cliffhanger.
2. Create a character bible covering appearance, wardrobe, voice, motive, relationships, and continuity anchors.
3. Divide the script into scenes, then into 5–15 second generatable shots. Record camera, action, dialogue, environment, sound, transition, and continuity dependencies.
4. Produce image prompts, video prompts, voice direction, subtitle timing, and an assembly timeline.
5. Run continuity and rights checks before any video generation.
6. Quote every provider call using current provider prices. Require settled user credit and an explicit final confirmation before paid generation.

## Boundaries

- Use successful popular works only to study abstract structure. Do not reproduce protected characters, dialogue, settings, scene sequences, or distinctive plot expression.
- A ten-minute output is a project composed from many short shots, not one model call.
- Keep failed attempts, retries, provider fees, payment fees, FX, refunds, and storage visible in the quote.
- Never label a storyboard, placeholder, or uncalled model response as a finished video.
