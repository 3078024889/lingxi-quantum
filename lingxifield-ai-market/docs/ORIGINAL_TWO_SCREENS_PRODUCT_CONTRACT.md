# LINGXIFIELD 原始两张效果图：产品与数据验收契约

## 不可偏离的产品原型
图一：全局 AI 平台行情总览；图二：单一 AI 平台资料与竞争比较。
设计基准来自项目负责人提供的两张原图，不重做陌生的第三套 UI。

### 图一：行情总榜
- 顶部：LINGXIFIELD 官方 Logo、问题式统一搜索框、排行榜 / AI 工具 / 对比 / 资讯 / 账号入口。
- 可读性：行业分类，简洁摘要指标，主体按产品排行的完整信息表格，右侧热门问题和快速比较。
- 主体数据：平台名称、功能分类、实际套餐与免费额度、已确认的使用方式/下载链接、可注明来源的采用率信号。
- SEO/GEO 只能使用真实测量方法的独立可复现结果；网站访问量、App 下载、行业融资不允许使用效果图数值充数。
- KPI 卡片无可用数据时显示“暂无可核验数据”，可以展示模型数和候选工具数，但要明确是来源计数，不冒称流量排名。

### 图二：详情页
- 平台名称和真实官方入口，可用渠道标识只在有来源时显示。
- 标签页：概览、功能、价格与额度、使用评价（来源摘要）、数据与排行（注明范围）、竞品比较、公司资料、最新变动。
- 价格应展示币种/计费周期/免费额度/要求银行卡或手机号/使用失败扣费规则，并标注出处和日期。
- 只有可查证的排名/下载/访问/融资/评分可以显示数字；未知一律“待核验”，不得根据主页流量猜测估值、用户评分。
- 优先保留详细但不拥挤的布局：左侧候选/相关产品；中央详情；右侧信息卡。移动端顺序展开。

## 产品定位和页面层次
用户：问题 → 答案 → 工具与功能 → 实价/免费额度/限制 → 官方入口。
厂商：排名和来源 → 竞品比较 → SEO/GEO 可见度 → 具体改进建议。
隐藏采集日志/敏感字段/评分算法细节，不让工程信息淹没选择过程。

## 品牌
- 仅使用用户已提供的官方金色圆形 LINGXIFIELD 原图；禁止生成、矢量重绘或用伪装形状代替。
- 未确定正确原图文件所在项目路径前保持文字标识，不臆造 Logo。
- 九语言及 zh/en/ja/ko/fr/de/es/pt/ar 路由与阿语 RTL，桌面/手机适配。
- 2 GB RAM 主机：分页、预计算、短 TTL，不在响应中下载整套原始源数据。

## 数据真实性门槛
- models.dev: 模型、服务商报价是第三方聚合，不能冒充厂商发布价格。
- Hugging Face: downloads/likes 仅代表该 Hub；不能称全网访问量或实际活跃用户。
- Similarweb: 仅在合法持有对应权限且采集成功时展示其估算数据，并明确估算口径。
- Google Trends: API Alpha 需要获批；无权限不声称监测实时趋势。
- GEO: 自建明确查询集/搜索引擎/地区/测量时间/重复次数，标为本站样本监测，而非全球公认排名。
- 用户评论须来自合法可引用来源，附时间和口径，不能生成“12,846 条评价”之类的数字。
- 不得把效果图中的 5.28B、298M、48.7B、4.8/5、9.8/10 等演示指标写为真实数据。
- 不合并 main、不生产部署、不接真实支付、不删除用户 D 盘文件，待全面验收后统一授权发布。

## 单批次验收
1. 首页保留图一主布局，进入平台有图二详情布局。
2. 每个可见数字能够回溯来源、单位、日期、统计范围。
3. 每个产品有可点击且核验的官网或工具使用入口。
4. 分类搜索、排序、分页、展开报价、比较及 zh/en/ar 手机显示有可运行证据。
5. 数据源失败时保留最近有效快照并提示采集时间；不显示伪趋势或伪增长率。
