# 邀请奖励：可择时使用的一次周额度重置

用户确认规则（2026-09-19）：被邀请人完成注册并实际充值会员后，邀请人获得一次周额度重置机会。奖励不自动开始倒计时；邀请人选择使用时才重置。不是把现有会员改成周套餐。

实现必须由支付核验触发，不能由浏览器提交“已付款”领取。每位被邀请人的首笔合格会员支付最多发放一次。注册归属确定后不可任意改邀请人，禁止自邀。发放、撤回、使用都要可追溯。

奖励状态：待使用 → 已使用。支付退款前未使用的奖励撤回；已使用奖励的退款处理必须另行定义，不能静默扣除现金余额。

使用必须在数据库事务中同时锁定奖励与用量窗口，幂等处理；同一次机会不能并发兑换两次。使用时建立新的七天用量窗口，不把剩余百分比与重置次数混为一谈。

界面显示：当前周期剩余用量、准确重置时间、可用重置机会数量、“使用一次，重置周额度”。兑换前显示重置后的额度与周期。没有真实计量记录时显示未开通，禁止展示模拟百分比。

尚待产品配置明确：哪一种 AI Agent 会员订单符合资格、每周额度单位与额度数、奖励是否到期、退款后的已用奖励规则、无有效会员时的权益范围。这些不能从 Codex 截图推断。SASI 创作任务继续采用人民币余额与确认预算。

当前为已确认规则记录，邀请归属、发奖事务和兑换接口尚未上线。
