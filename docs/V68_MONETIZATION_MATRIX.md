## 为什么批量 PDF 属于收费层
成熟 PDF 平台普遍把 batch / workflow 放到 Pro/Premium 层。批量的价值不是单个动作本身，而是一次对多个文件重复执行一致流程，减少重复上传和下载。

## V68 批量边界
一个批次：
- 最多 20 个 PDF
- 总大小最多 400 MB
- 可组合：清除元数据、旋转、水印、页码、表单扁平化
- 可最终合并为一个 PDF
- OCR / Word / 真脱敏 / 签名不包含在 ¥3 批次价，避免专业能力被低价打包
