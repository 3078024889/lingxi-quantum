# V69 Product Constitution

## Product rule
- Browser-local, low marginal-cost utility actions are free acquisition tools.
- AI restoration, OCR, transcription/translation, professional exports, batch productivity and storage-backed services may be paid.
- Image/video watermark cleanup remains paid/freemium according to the existing policy.
- Reverse video, loop video and stop-motion/Boomerang are free and local; no payment step.
- Every paid practical-tool amount must use the same numeric value in CNY and USD: ¥1 = $1, ¥3 = $3, etc.
- Quality-gated capabilities remain disabled until they meet production quality.

## V69 new free search entrances
- Regex Tester
- Text Diff
- CSV to JSON
- XML Formatter
- JWT Decoder
- URL Parser
- Case Converter
- Number Base Converter

All eight run in the browser and do not upload user input.

## Competitive patterns reviewed
- PDF24: broad PDF task coverage and one-task-per-search-entry architecture.
- Sejda: Bates numbering, bookmarks, repair, grayscale, deskew and focused task pages.
- qpdf/pdfcpu: bottom-layer PDF capabilities should come from proven engines rather than UI-only simulations.
- Developer-tool sites: one local capability core can serve multiple long-tail task URLs.

## Next PDF deep-core gate
Candidate capabilities for the next package: overlay/underlay, page size, flip, grayscale, header/footer, Bates, bookmarks, attachments/images extraction, annotations removal, linearization, repair, protect/unlock/permissions, PDF/A and signature verification. Deep capabilities must pass a real-engine gate before public launch.
