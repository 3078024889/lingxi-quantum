## 2. 第一刀实现范围（只这五条）

1. **Planet Health**：`/api/planet/health` + 后台页，聚合现有 audit 绿/红与 generated_at。  
2. **一条真实旅程巡检**：任选高频工具：上传 → 处理 → 下载 → 断言结果文件。  
3. **上传隔离区**：UPLOAD → QUARANTINE → VALIDATE → PROCESS；恶意只毁隔离副本，**保留 SHA256 证据**。  
4. **Session / Token 吊销钩子**：高置信异常 → revoke（L1）。  
5. **硬闸**：支付金额、删库、提权、RLS 放宽 → 仅人工。
