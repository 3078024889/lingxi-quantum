# SASI 创作工作台改造与交付状态

## 本轮用户要求

先完成 SASI 创作工作台的真实入口、支付、任务执行与交付，再逐个推进书本 SASI与小工具。前端采用 Codex / GPT 式统一创作界面，复杂的导演、分镜、构建、部署流程留在代码与 Skills 中。允许导入剧本、人物名、角色图、场景图和其他资产；目标是确认后完成短剧或构建网站。

- 顶部充值文字放大、明显滚动；右上角头像增加充值入口。
- 左侧导航放大、简化；“探索与实践”更名为“意识显化”。
- 保留并接通真实充值，不能用按钮、模拟订单或开关冒充商户/结算验收。
- 小工具和书本资料上传均需支持至少 1GB 以上；不能仅修改前端上限。
- “AI知识库”改为让书本与资料活起来的 Agent 产品。用户价值是读懂、引用、复用方法、调用工具、把知识用于作品和研究；不止存文件或关键词检索。
- 命名和文案从用户问题出发。本轮暂用“书本 SASI / 让书本活起来”；当前能力仍明确是本地原文检索，不能把未实现的 Agent 执行写成已开放。
- 用户提及 Paper2Agent 作为方向示例，本轮没有据此宣称本产品已具备论文方法执行能力。
- 保留已工作的意识显化；不改动其他尚未完成模块的真实状态。

- 前后端与项目附件描述共用 2GiB 能力上限；部署有效上限由 `SASI_STORAGE_MAX_FILE_BYTES` 控制，默认 50MiB，接口和界面一致。
- 素材上传票据增加同源校验和套餐上限校验。

## 已执行的远端变更

在已连接的 Supabase 项目上应用 `sasi_large_asset_uploads`：只放宽 `sasi_assets` 两个大小约束到 2147483648 字节。RLS 仍启用，无删除或放宽所有权策略。迁移文件已落盘。

试图调整 Storage 2GiB 上限时，管理接口返回 HTTP 402：当前套餐只允许 52,428,800 字节，需要升级付费套餐。该调整失败，未购买套餐，存储上限没有被提高。私有 bucket 记录虽为 100MiB，但项目全局上限是 50MiB；页面按有效上限显示。

最新决定：用户不能支付海外卡套餐，优先保留 Supabase 数据库并接国内对象存储，不再以升级 Pro 为前提。当前真实上限保持50MiB；未配置国内存储前不把页面改成假2GB。不要直接推送仓库完整 config.toml，它含有与线上不同的 Auth 配置。

## 生产阻塞：不得标记已上线

2026-09-20 读取公开 `/api/sasi/status`：支付宝、微信为已配置；PayPal 未配置；视频供应商、productionAccountReady、executionReady、refundFlowTested、usageSettlementTested、contentLabelingReady 和 productionReady 均为 false。

本地没有 ARK_API_KEY、XAI_API_KEY、OPENAI_API_KEY、DASHSCOPE_API_KEY。SASI_BILLING_ENABLED 和 SASI_JOBS_ENABLED 为 false，退款和结算验收标志尚未通过。不可盲目改成 true。

当前生产接口实现单个视频镜头任务，不等于已实现完整短剧自动合成；构建节点持久化不等于有代码执行沙箱、Git 写入、构建和真实部署执行器。附加图片/剧本还需完成解析、资产绑定、角色连续性、分镜生产、配音、合成等端到端交付链。

本轮没有真实付款、商户回调、退款、付费视频生成或网站发布的成功证据。也没有用户登录后的全流程浏览器验收。用户已选定火山引擎 Seedance，采用用户自带API；国内存储账号路线仍待确认。凭据通过安全配置提供，不发送到聊天。
