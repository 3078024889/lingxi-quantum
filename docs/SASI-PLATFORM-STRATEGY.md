# SASI 平台策略 / Platform Strategy

更新日期 / Updated: 2026-09-08

## 一句话定位

SASI 不是模型集合、提示词工具或算力转售页面。它是面向结果的智能生产系统：用户表达目标，SASI 负责理解、策划、能力编排、制作、审校与交付。

**品牌表达：** 交付你的构想，不必管理它背后的复杂系统。

## 产品原则

1. **结果先于工具。** 首页从用户目标出发，不以模型品牌、接口或参数作为入口。
2. **能力先于供应商。** 用户看到叙事与决策、产品与工程、视觉世界构建、动态影像制作、声音叙事；具体供应商只存在于内部路由与运营后台。
3. **制作提案先于执行。** 系统先完成目标理解、范围推演、制作规格、交付预期与投入边界，再请求最终授权。
4. **创作主权贯穿全程。** 每一生产节点均可审阅、锁定、局部重做与版本回退，上游改变不会静默重跑下游。
5. **平台不替用户垫付未授权资源。** 到账确认和项目授权都完成后，才锁定制作额度并创建外部任务；未使用部分归还制作账户。
6. **不伪装未完成能力。** 上传、执行、支付、外部接入和创作者发布在基础设施就绪前保持受控预览。

金额仍须在最终授权与法律规则中清晰、准确地披露；品牌语言的提升不得削弱交易透明度。

## 编排结构

```text
用户目标
  ↓
意图识别
  ↓
创作总控（确定结果、范围与验收标准）
  ↓
制作统筹（拆分节点、依赖、规格与投入边界）
  ↓
能力路由（文本 / 工程 / 视觉 / 动态 / 声音）
  ↓
逐节点执行与品质审校
  ↓
可追溯交付
```

SASI Auto 对普通用户隐藏供应商选择。未来的专业接入位于独立区域，采用服务端加密、权限隔离、可撤销授权与脱敏展示。

## 双生产系统

- **SASI Build：** 需求澄清 → 产品规划 → 架构 → 实现 → 测试 → 安全审阅 → 预览 → 部署 → 公网证据。
- **SASI Drama：** 项目理解 → 叙事结构 → 人物与场景身份板 → 故事板 → 精分镜 → 声音 → 镜头 → Timeline → 字幕与母版。

两者共享项目、资产、节点依赖、版本、授权、任务、审计与交付层，不复制账户或结算逻辑。

## 商业与资金边界

SASI 采用预授权生产模式，而不是先执行后追款：

1. 用户建立制作储备；
2. 支付渠道确认到账；
3. SASI 形成制作提案；
4. 用户授权项目投入上限；
5. 账本原子锁定制作额度；
6. 系统才创建外部制作任务；
7. 按真实执行结算，归还未使用部分。

对外展示的是作品规格、制作额度、授权上限、交付预期和失败处理。供应商采购价、平台毛利、路由权重、汇率缓冲与重试准备金属于内部运营数据，不得进入公共目录或客户端包。

## 分阶段建设

### Foundation

- 对象存储、安全上传与资产索引
- 项目、节点、任务与审计数据层
- 单一低风险能力的端到端闭环
- 制作账户的到账、锁定、结算、归还与退还

### Production

- Drama 身份板、故事板、镜头与 Timeline
- Build 仓库沙箱、验证与部署证据
- 任务队列、幂等、重试、限流与质量审校

### Platform

- 多能力自动路由与故障切换
- 专业外部能力接入
- 创作者能力的隔离运行、审阅、授权与结算
- 团队协作、企业制作与批量交付

## 当前代码落点

- `app/sasi/SasiWorkspace.tsx`：目标入口、双工作室、能力中枢、制作账户与受控预览。
- `lib/sasi/catalog.ts`：用户可见的制作规格、能力谱系、能力作品与制作提案。
- `lib/sasi/provider-economics.ts`：仅服务端使用的供应成本基线。
- `app/api/sasi/catalog/route.ts`：只输出公共能力目录，不输出供应商采购数据。
- `app/api/sasi/prepare/route.ts`：执行前制作推演，不触发真实任务或资金动作。
- `app/api/sasi/projects/route.ts`：登录用户的项目创建与最近项目读取；创建请求具备幂等保护。
- `lib/sasi/project-proposal.ts`：Build 与 Drama 共用的输入净化、制作提案与初始节点定义。
- `app/api/sasi/assets/prepare/route.ts`：为登录用户签发绑定项目与隔离路径的短时上传票据。
- `app/api/sasi/assets/[id]/inspect/route.ts`：核验对象，小型文本建立摘要与检索索引，二进制进入外部扫描门禁。
- `app/api/sasi/projects/[id]/route.ts`：只向项目所有者返回节点与资产安全状态。
- `supabase/migrations/20260908090000_sasi_foundation.sql`：制作账户、不可变账本、项目节点、依赖图、资产与任务的可部署基础迁移。
