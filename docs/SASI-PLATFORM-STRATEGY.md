# SASI 智能软件市场平台策略

更新日期：2026-11-12

## 一句话定位

SASI 是面向全球开发者与软件用户的智能软件交易市场，提供经过审核的软件商品、MT5 EA、交易指标、源码授权、安装文档、订单权益与安全自动交付。

**品牌表达：** 让可信的软件商品被发现、被验证、被授权，并安全交付。

## 产品原则

1. **商品信息真实。** 版本、兼容环境、功能范围、授权类型、价格、更新日期和安装要求必须可核验。
2. **先审后售。** 商品文件、图片、安装包和许可文件必须经过格式、哈希与安全检查。
3. **交易状态唯一。** 订单状态由服务端和支付回调确认，前端展示不能自行推断支付成功。
4. **交付最小授权。** 下载地址短时有效、绑定订单和购买者，禁止公开永久文件地址。
5. **开发者与买家隔离。** 卖家只能管理获授权商品与结算信息，买家只能访问已获得权益的订单和文件。
6. **历史数据不可被页面更新覆盖。** 订单、账本、退款、下载与结算记录必须保留审计链。
7. **九语言信息一致。** 公开商品、市场导航、卖家入口和交易说明在九种语言中保持准确表达。

## 商品数据契约

每个公开商品至少包含：
- 唯一商品 ID、名称、分类和开发者身份；
- 当前版本、发布日期、更新说明；
- 支持平台、运行环境、依赖项和安装步骤；
- 功能边界、风险说明与兼容性限制；
- 授权类型、授权范围、使用期限；
- 标价币种、价格、税费/费用披露；
- 文件校验状态、审核状态和交付状态；
- 退款、售后和更新政策。

未完成审核、文件校验失败或支付渠道不可用时，商品不得呈现为可正常购买。

## 交易与交付不变量

1. 创建订单时保存商品版本、价格、币种和授权快照。
2. 支付回调必须验证签名、商户身份、金额、币种、订单号和交易状态。
3. 支付事件采用幂等键；重复回调不能重复记账、重复发权益或重复结算。
4. 只有服务端确认支付成功后才能生成购买权益。
5. 下载票据绑定用户、订单、商品版本和过期时间。
6. 私有对象存储不公开桶目录、对象密钥或永久下载地址。
7. 退款与撤销权益必须通过账本事件处理，不得直接覆盖历史记录。
8. 卖家结算只根据已完成且符合规则的订单计算。

## 安全与权限边界

- 买家、卖家、审核员、财务和管理员采用独立权限。
- 文件上传执行大小限制、MIME 与文件签名核验、恶意文件扫描和 SHA-256 计算。
- ZIP 等归档文件必须防止路径穿越、压缩炸弹和解压覆盖。
- 所有下载接口重新校验会话、订单权益和文件状态。
- 管理操作记录操作者、对象、动作、时间与结果。
- 公开 API 不返回私钥、服务角色密钥、供应商内部成本或其他用户私有数据。

## SEO / GEO 与公开事实

- /sasi 是软件市场主入口。
- /sasi/seller 是开发者服务入口。
- /sasi/delivery 是订单交付说明。
- /discover/sasi-software-marketplace、/discover/mt5-ea-source-code、/discover/software-licensing-delivery、/discover/developer-software-publishing 是市场主题页。
- 页面标题、结构化数据、sitemap、canonical、hreflang、llms.txt 和 llms-full.txt 必须与实际可见商品功能一致。
- 不为不存在的功能生成搜索入口，不把历史路线写成当前产品承诺。

## 发布门禁

### 源码与构建
- TypeScript、Lint、生产构建通过。
- 市场、卖家、订单、钱包、支付、交付模块的依赖图无断链。

### 自动化测试
- 商品审核与上下架。
- 卖家权限与买家隔离。
- 支付回调签名、金额、币种和幂等。
- 订单权益、重复通知和退款。
- 私有文件访问、短时下载与越权测试。
- 九语言导航和公开 SEO 文案。

### 生产验收
- 双域首页、SIAI、工具、SASI、账户、钱包和卖家入口。
- 商品列表、商品详情、订单、支付回调与交付。
- 匿名私有接口继续返回预期的 401/403。
- 历史订单与交付记录保持可读。
- llms.txt、llms-full.txt、robots.txt 和 sitemap 与发布版本一致。

只有当前源码构建、测试、发布和公网探测全部通过，才标记为全面上线。
