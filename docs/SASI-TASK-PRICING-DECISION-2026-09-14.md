# SASI 任务收费与产品改造决策

核对日期：2026-09-14。依据用户《SASI 唯一收费逻辑与任务计费规范 V1》及本次补充。只适用于 SASI 第一层，不改变意识显化连接周期。

## 产品结论

SASI 值得做的部分是持续项目上下文、人物与世界连续性、可编辑生产链、预算保护及真正交付。仅集合模型入口、显示导演人像和生成按钮，差异不足。当前不能声称一键成片已贯通，也不能保证任何作品成为爆款。

用户流程保持一条：输入剧本 → 填写集数和每集时长 → 确认制作规格与交付内容 → 查看总预算 → 确认执行或调整方案。人物、故事板、镜头和版本都属于同一个可继续的项目。需要批量生成时，由后端任务链负责调度，不能让浏览器循环提交高成本任务。

## 收费决定

前台只有“本次任务预算上限”和结算金额。后台保留供应商成本、执行环境成本、存储带宽、工作流价值和利润，不拆出用户可见的导演费或 Skill 费。

视频使用已核验线路的人民币秒价。集数乘每集秒数是交付规模，不一定等于供应商计费秒数：多候选、返工和重试都可能增加后者。用户批准的是包含重试边界的总预算，不能因系统自行反复尝试而突破上限。供应商未计费的失败不能向用户计费；已发生的不可退费用须有证据。修改需求产生额外任务时重新报价。

利润由统一任务价与成本之差产生。首发秒价应根据同一画幅、分辨率、时长、生成次数、声音配置的真实样本建立，不能把某个模型最低公开秒价直接当作完整短剧成本。价格必须定期更新，失效时停止报价。

编程采用任务预算，后台按模型实际用量、沙箱运行、构建测试和一次性部署工作计入成本。可通过 Codex SDK 或其他地区适用的模型/Agent API 实现；SDK 本身不代替隔离运行、文件权限、测试、版本控制与部署凭证。用户自己的模型账户承担 BYOK 模型账单，SASI 若另收工作流任务价，必须在本次确认单明确该总价不含供应商直接收取的部分，避免重复收模型成本。

域名购买、云主机和持续数据库/托管属于持续运营支出。接用户自己的云账户时在部署前说明归属；未来若提供 SASI 托管，应独立说明运行周期，不能偷偷并入一次建站预算。

## 验收方向

电影级是制作规格与审校标准：角色一致、对白同步、镜头衔接、字幕与声音、清晰度及可播放文件。爆款取决于内容、受众和传播，不能变成付款承诺。先在批准的预算内完成代表镜头，锁定视觉与人物，再扩展批次；不强迫用户反复选择模型。

## 本次代码落地

- 首页缩为三个任务入口，工具入口轻量化；导演图片变为横向比例，减少重复大图。
- 页面 URL 与导航同步，刷新恢复 code/connections 等入口并处理浏览器返回。
- 集数和每集秒数独立保存，20 × 60 正确记为 1200 秒；预算按整数分保存。
- 移除前端固定秒价。服务端按模型、规格、有效期读取版本化价目；未配置或过期不报价；报价版本变化要求重报。
- 免费知识检索不会因存在平台密钥而自动调用付费模型。
- 成功生成不再直接以报价全额结算：需要可信供应商计费用量。缺少证据显示待对账，超预算不直接扣款。
- 实际用量结算增加独立生产验收门控，未验收不可开启收费生产。

## 尚未完成的生产闭环

公开 /api/sasi/status 在本次核对中 productionReady=false。需要完成真实价目配置、供应商用量/失败账单适配、失败部分结算、账单事件幂等和对账。已有数据库账本并不等于这些验收已通过。

## 与《哥白尼》的关系

已提取用户 PDF，重点核对 PDF 第 51–55 页佩德罗演示，以及后续学习/自改代码相关段落。小说描述了自行学习、形成连续性假设、反向解释选择和自设目标；它没有提供足以复现实验的可执行训练算法、数据集、评测协议与运行证据。

SASI 仓库可见规则导演、Foundry 检索、角色永久身份和连续性状态。用户提供的二十瓦特本地目录另有树突模型、母版搜索及演化竞技脚本；其自述是离线学习实验，而非已完成的通用智能。当前未对它运行独立能力评测，也未核验所有实验日志，因此不能采用“85%”或“完美复制”作为已验证结论。

工程上应以可复现的跨任务表现、正确恢复上下文、持续学习前后对照、隔离自改与回归测试衡量进展。小说可提供产品灵感，不能替代这些证据。

## 配置和本次验证

`SASI_VIDEO_RATES_JSON` 为服务端 JSON 数组，每条必须包含 provider、model、quality、retailFenPerSecond、supplierFenPerSecond、validUntil。金额均为整数分；供应商成本与售价必须来源于已核验采购和制作规格，不能使用演示数字配置生产。报价有效期最多十分钟，并绑定价目版本。现阶段未配置真实价目。

生产构建、类型检查和两项 SASI 审计通过。独立测试覆盖价格缺失/过期/变化、超预算拒扣、结余释放、20 集乘每集 60 秒、整数分预算及免费检索不调用付费模型。Edge 浏览器检查覆盖桌面首页、导演入口与刷新/返回、编程和模型入口、390px 手机无横向溢出，以及真实本地规划 API。没有调用付费生成，也没有以这些检查替代真实生产账单验收。
