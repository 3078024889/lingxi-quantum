# Third-Party Software, Models, and Datasets

This document tracks third-party software, model weights, datasets, binaries, SDKs, and hosted services that may have licensing or attribution requirements beyond the application repository itself.

## Rule

Do not assume that:

- an open-source repository implies open model weights
- an open model implies unrestricted commercial use
- a permissive software license covers datasets
- a hosted API allows redistribution
- a frontend package license covers bundled binaries

For every important third-party component, verify:

1. software license
2. model / weight license
3. dataset license
4. commercial-use terms
5. attribution obligations
6. redistribution restrictions
7. acceptable-use restrictions

## Review points

Review this document when:

- adding a model provider
- bundling model weights
- adding browser-side WASM / native binaries
- incorporating code from another repository
- adding a dataset
- changing a hosted API
- shipping downloadable model assets
