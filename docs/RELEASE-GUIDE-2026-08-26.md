# 灵犀场双语 UI 与小程序发布步骤

本次版本已经完成网页构建、出版 UI 审计与安全审计。网页与小程序来自同一仓库，但需要分别发布。

## 一、上传到 GitHub

1. 打开 GitHub Desktop，选择仓库 `lingxi-quantum`。
2. 把 ZIP 解压后的文件复制到本地仓库目录，遇到同名文件选择替换。不要删除 `.git` 文件夹。
3. 回到 GitHub Desktop，在 Summary 输入：`Update bilingual Field Insights and Mini Program sharing`。
4. 点击 `Commit to main`，再点击顶部 `Push origin`。
5. 等待网站自动部署完成，然后分别检查 `https://lingxifield.com` 与 `https://lingxifield.cn`。

## 二、发布微信小程序

1. 打开微信开发者工具，导入解压后仓库中的 `miniapp` 文件夹。
2. 确认 AppID 是灵犀场正式小程序的 AppID，点击“编译”。
3. 在真机预览中进入任意精测网页，点击右上角菜单，确认“转发给朋友”“分享到朋友圈”和“复制链接”可用。
4. 分别打开中文和英文模式，核对标题、正文、按钮与报告名称。
5. 点击右上角“上传”，版本号填写 `1.5.0`，备注填写：“场域精测全面升级：八项产品内部入口统一为完整中英文内容，升级深度关系共振、今日潮汐与桃花磁场指数命名；优化产品表单、报告展示、小程序分享及复制链接支持；更新电脑端30秒入场视频并修复人物画面裁切。”
6. 登录微信公众平台，在“版本管理”中提交审核；审核通过后点击“发布”。

## 三、大厅视频替换

当前桌面视频为 `public/images/entrance/lingxi-opening-desktop.mp4`。新视频建议为 H.264 MP4、1920×1080 或更高、16:9，人物面部位于画面安全区内，文件控制在约 25 MB。替换时还应重新生成 `public/images/entrance/lingxi-opening-poster-desktop.jpg`。不要只对旧视频强行放大或锐化；源片没有的人脸细节无法通过网页恢复。

## 四、发布后必查

- 首页中文与英文切换；
- 八个场域精测入口与 CTA；
- “深度关系共振”已替代原“亲密关系”用户界面文字；
- “今日潮汐 / Today’s Tide”已替代旧名称，包括完整报告；
- 手机与电脑首屏；
- 小程序转发、朋友圈、复制链接；
- 已购报告仍可打开，旧订单不受内部兼容字段保留影响。
