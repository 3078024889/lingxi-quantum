- 生产站点：`https://lingxifield.com`。
- 通过 Firefox 自动化实际加载 `/tools`，识别 **123 个不同的工具入口**。
- 对上述 123 个入口逐一发送 HTTP 请求：**123/123 返回 HTTP 200，未发现 4xx/5xx 或服务端错误页**。这只是路由健康度，不是功能通过率。
- 九语言 `zh/en/ja/ko/fr/de/es/pt/ar` 的工具目录均返回 HTTP 200；在 375px 视口宽度下 `documentElement.scrollWidth === innerWidth`；阿拉伯语 `dir=rtl`，其他语言 `dir=ltr`。此项不覆盖完整触控操作。

## 验收判定

`ROUTE_OK` 只表示 HTTP 成功；`FILE_OUTPUT_PASS` 必须验证生成文件的内容；`SHARE_MOCK_PASS` 只证明浏览器调用/文件字节正确；`WECHAT_DEVICE_PASS` 必须由实际微信内置浏览器和目标设备验收。未测试的功能保持 `UNVERIFIED`。
