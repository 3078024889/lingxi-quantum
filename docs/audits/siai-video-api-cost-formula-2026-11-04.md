# SIAI 视频 / 短剧与开发者 API 费用公式审计（2026-11-04）

状态：**非部署的候选代码**。候选平台仍未通过人工完整上榜审核。本批只对已核实的单独 API 单价添加预算工具，不解除 B006 的非公开目录审批门禁。

## 计费架构
- 直接生成视频：`视频生成费 = 每段时长 × 段数 × 对应分辨率的官方输出单价`。
- 视频参考素材：`视频输入费 = 输入秒数/段 × 段数 × 官方输入单价`。如 MiniMax H3，其参考视频按同输出分辨率单价计。图片：`max(0,每段参考图数-免费张数) × 段数 × 超额每图单价`。
- 最终可估现金费用 = 输出生成费 + 有明确定价的输入参考素材费。重试、第三方配音/音频、生成失败重跑、税、专属折扣、手续费不能擅自计入；如无可复核价格，必须显示“未核实/不计算”。
- API 文本：`调用次数 × (每次输入Token × 官方输入价/1,000,000 + 每次输出Token × 官方输出价/1,000,000)`。缓存命中、工具、区域加价、长上下文、批处理和渠道费不混进标准价。
- 网页会员积分只展示积分与套餐使用率，不能当成独立 API 钱款；两种货币为各自原始价格，不进行未经授权汇率换算。
- 只给正式获得来源的 SKU 自动计算，不把开发者 SDK 的免费安装等同于免费的 API。

## 基于成熟平台实现约束
- 开源模型费用跟踪工具和供应商官方价格体系普遍按“模型+单位+平台+时点”分开计费；这里继续沿用现有第一方 `market-rate-catalog` 和纯计算模块，避免未经安全审计引入大型外部依赖。
- 不复制未经确认许可的第三方组件或价格数据爬虫，不让浏览器获得任何真实供应商 API Key。

## 用户体验
- 主界面只展示视频/短剧或 API 两种模式、简单数量及即时总额。
- 视频有 1 段、1 分钟和 5 分钟快捷预算；最终显示**实际拼接时长**而非输入时长的近似值。
- API 默认每次 2000 输入 + 500 输出 Token，允许填写调用次数，显示总额和每次费用。
- 复杂的 32 平台账单对照表默认折叠，用户需要时再打开；不是把搜索筛选条件折叠。
- 九语言新控件均有对应标签。
- 不改变主榜 32 条公开核心 SKU，不将新增 10 条候选正式上榜。
