# V317 · 9D 可交互结构、八域 24 题与生命原型年度汇流

## 本次完成

- 9D 视频从 HEVC 转为 H.264 High / yuv420p / 1280×720，体积由约 51 MB 降至约 14.8 MB；网页与小程序统一引用兼容版本。
- 网页 9D 窗口支持桌面拖动、视频与结构导航图切换；桌面「场域精测」旧下拉替换为可点击的 9D 场域图。
- 小程序 9D 晶体可拖动，避免遮挡正文与底部操作；视频加载失败时显示结构图，不再留下黑色空窗。
- 八个独立场域统一为 24 个真实情境问题；生命原型不再提供第九份问卷。
- 报告改为「解决什么 → 结构机制 → 现实影响 → 可验证动作」，并按产品装载仓库中的原始出版图。
- 生命原型仅在一年内八个基础场域均已完成且已开启时自动生成，不单独售卖；结果保留跨域增强、弱参与与结构张力，不做八份报告摘要。
- 生命原型从 120 张现有出版图中按八域证据签名确定图片；不再使用 64 枚生命灵签。
- 小程序「我的场域」与网页「场域订单」均显示已授权树突档案；未付费测评不会通过直达链接越权阅读。

## 数据库

本版复用 V314 已建立的 `mini_dendrite_assessments` 与账户迁移 RPC，不新增表或字段，因此没有必须执行的新 SQL。若生产库尚未运行 V314 SQL，需先执行 `sql-history/SQL-v314-mini-dendrite-assessments.sql`。
