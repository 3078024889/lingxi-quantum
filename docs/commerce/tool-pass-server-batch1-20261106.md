## 历史媒体报价防重复执行（隔离候选）
- 对转写、文字翻译、语音合成分别使用数据库原子执行保留记录，一张历史已付报价单不能无限重放同一执行阶段。
- 必须同时核对已支付订单、历史已购交付授权、报价账户、工具类型与远程操作类型；拒绝跨账户、跨工具与已退款订单。
- 兼容性风险：同一报价如果原本包含多段翻译或配音，需要核对原始购买范围和逐段交付记录；当前保守限制为每阶段一次。旧媒体用户验收通过前不可上线。
- 新迁移仅在 PostgreSQL 17 隔离测试运行，不执行正式数据库修改。
