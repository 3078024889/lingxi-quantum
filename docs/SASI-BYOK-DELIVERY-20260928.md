# SASI 创作扩展与上线条件

## 本次代码交付

- 视频：多集、最多 60 镜／合计 600 秒；服务端整批保存报价，按集汇总，确认后逐镜提交。每个任务原子领取，提交结果不确定时停止后续请求。刷新页面可从项目记录恢复查询。
- 参考图：沿用项目素材库，核验所有权、大小、格式和内容哈希，按模型支持的首帧／多图模式发送；不承诺角色绝对一致。
- 分辨率：只展示管理员核验过的模型／480p、720p、1080p 组合；不把每一种分辨率强塞给不支持的模型。
- 图片：新增用户自有火山凭据的单张 Seedream 生成、报价、确认、历史记录及结果保存入口，不使用平台密钥。
- 文本：聊天、导演、原文证据问答、静态网站生成共用用户凭据和报价确认流程；取消“换模型但仍按旧模型报价”的环境变量旁路。
- 网站：返回完整静态 HTML，预览禁脚本／网络／表单；下载经过清理、带 CSP 的 ZIP。没有自动发布到客户账户，没有动态后端。
- 分享：验证两个线上域名对 Twitterbot 返回新图，远端图片 SHA256 与仓库相同。新增 `/share/20260928` 独立分享地址，便于重新抓取，无法保证第三方清空旧消息缓存。
- 文案：创作入口改为成果导向；连接、预算归属和限制放在用户需要决策的位置，新增状态／错误码的用户文案映射。

## 环境配置（必须依据实际开通模型与官方报价填写）

- `SASI_BYOK_VIDEO_ENABLED=true`
- `SASI_BYOK_SEEDANCE_PROFILES`：JSON 数组，每项沿用 `SeedanceProfile`。字段 `model,resolution,generateAudio,maxDuration,estimatedFenPerSecond,validUntil,priceSource,imageMode`。旧的单项 `SASI_BYOK_SEEDANCE_PROFILE` 保持兼容。
- `SASI_BYOK_TEXT_PROFILE`：`model,inputYuanPerMillion,outputYuanPerMillion,maxOutputTokens,validUntil,priceSource`。输出上限 1024–16384。配置缺失时旧配置会因过期拒绝付费请求，不擅自延长有效期。
- `SASI_BYOK_IMAGE_PROFILE`：`model,size,estimatedFen,validUntil,priceSource`。size 为已验证的 `1K/2K/4K` 之一，每次一张；不是所有模型都支持所有尺寸。
- `priceSource` 仅允许官方 HTTPS 文档域名，配置过期立即停止新报价。没有编造当前价格或代用户开通付费服务。

## 验证边界与仍未完成项

自动化测试使用供应商响应夹具验证输入、预算、权限、并发和超时，不是实际出图出片。没有消耗用户 API 余额。

多镜头付费提交目前需要保持页面打开；已提交任务在供应商运行。自动后台调度、断线自动续交、逐集自动下载合成尚未实现。现有合成器需要用户保存镜头后选择本地文件。

参考图用于视频生成；新增图片入口目前是文生图，不包含图片编辑或全模态聊天。导演分镜输出仍限制为一分钟样片，多集可手工导入镜头清单。书本引用检查核对编号存在，不能证明模型结论一定正确。

实用工具的 59 个入口源码检查通过，不等于 59 项逐个处理真实文件已通过。OCR、转录与浏览器翻译的模型下载、浏览器支持、输出质量仍需各自验收。

新增真实文件验证：PDF 合并保留页序、指定页提取、无效页码拒绝、PNG 转 PDF 保留宽高比、损坏 PDF 拒绝。浏览器测试使用响应夹具核验每集费用、确认前零提交、顺序提交、390px 布局、禁脚本网站预览及 ZIP 下载；不能据此宣称供应商真实出片。

视频页文案按用户定稿：标题“描述一个镜头，生成一段视频”，副文案说明人物／动作／场景／镜头，主按钮“生成视频”，费用提示独立出现，模型信息位于折叠设置中，密钥配置只在连接页面。
