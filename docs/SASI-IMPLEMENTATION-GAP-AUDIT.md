# SASI 实施差距审计 / Implementation Gap Audit

更新日期 / Updated: 2026-09-07

本文件区分三种状态，避免把界面、预检和真实生成混为一谈：

- **已实现 / Implemented**：用户现在可以实际看到或操作。
- **受控预览 / Guarded preview**：产品交互已存在，但不会发生付费、外部写入或模型调用。
- **未开放 / Not enabled**：必须先完成基础设施、安全或结算能力。

## 已实现 / Implemented

- 根路径 `/` 是 SASI 正式首页，`/sasi` 永久跳转到 `/`。
- SASI Drama 与 SASI Build 是同等级入口。
- 中英文、明暗主题、移动端侧栏。
- 首页统一输入框：文本、点击选择、多文件、拖拽、粘贴图片、本地附件暂存。
- 附件按剧本/媒体或代码/ZIP 自动建议 Drama 或 Build。
- 普通模式使用 SASI Auto；具体 Provider 只在高级设置和模型连接中出现。
- 动态剧集建议，不预设 100 集。
- 5–600 秒目标时长、人民币预算、快速/高清/电影级质量。
- Budget Quality Guard：预算差额可见，禁止静默降质。
- Drama 十阶段可编辑生产链在界面中完整呈现。
- Skills 的发现、我的、创建/上传/发布信息架构。
- 第二层入口：意识显化、场域精测、重塑潜意识 FREE、修炼技术 FREE、我的场域。
- 双语法律与规则入口。

## 受控预览 / Guarded preview

- Build/Drama 项目预检与费用测算。
- 本地附件只保留文件名、大小和类型；没有上传到云端，也不会执行其中代码。
- 模型连接页展示 Provider 和用途，但不会收集 API Key。
- 余额充值套餐可见，但账本与支付回调完成前不会收款。
- Skill 市场展示价格结构，但用户发布与交易仍关闭。

## 未开放 / Not enabled

- SASI Upload Hub 的对象存储、分片上传、断点续传、签名 URL、文件扫描、EXIF 清理和项目资产库。
- DOCX/PDF/图片/音视频/ZIP 的服务端解析与索引。
- GitHub OAuth、仓库克隆、代码沙箱、测试与部署执行器。
- 视频、图片、配音和大模型 Provider 的真实调用及自动故障转移。
- 人物/场景身份板的持久化引用和跨镜头一致性引擎。
- Timeline 编辑器、字幕轨、配音轨、BGM、成片合成与导出标识。
- SASI 钱包数据库迁移、支付宝/微信充值回调、余额冻结、结算、释放和退款。
- BYOK 的加密保存、连通测试、删除与密钥轮换。
- Skill 沙箱、权限清单、审核、恶意文件扫描、交易与创作者结算。
- 生成任务队列、幂等、重试、并发限制、监控与审计日志。

## 上线顺序 / Launch order

1. 对象存储与安全上传。
2. 项目、资产与任务数据库迁移。
3. 单一低成本 Provider 的完整任务闭环。
4. 余额充值、冻结、结算、失败释放与退款。
5. Drama 身份板、故事板、镜头、Timeline 闭环。
6. Build 仓库沙箱与部署闭环。
7. BYOK。
8. 用户 Skill 市场。

任何未开放能力都不得在前台伪装为已执行。 / No disabled capability may be presented as executed.
