# SASI 实施差距审计 / Implementation Gap Audit

更新日期 / Updated: 2026-09-08

本文件区分三种状态，避免把界面、预检和真实生成混为一谈：

- **已实现 / Implemented**：用户现在可以实际看到或操作。
- **受控预览 / Guarded preview**：产品交互已存在，但不会发生付费、外部写入或模型调用。
- **未开放 / Not enabled**：必须先完成基础设施、安全或结算能力。

## 已实现 / Implemented

- 根路径 `/` 是 SASI 正式首页，`/sasi` 永久跳转到 `/`。
- SASI Drama 与 SASI Build 是同等级入口。
- 中英文、明暗主题、移动端侧栏。
- 首页统一输入框：文本、点击选择、多文件、拖拽、粘贴图片、本地附件暂存。
- 附件按剧本/媒体或代码/ZIP 自动建议 Drama 或 Build。
- 普通模式使用 SASI Auto；前台以能力谱系呈现，不展示供应商采购层。
- 动态剧集建议，不预设 100 集。
- 5–600 秒目标时长、制作额度投入边界与三级制作规格。
- Production Envelope：额度差额可见，禁止静默降低制作规格。
- Drama 十阶段可编辑生产链在界面中完整呈现。
- 能力作品的探索、我的能力、编制与发布信息架构。
- 第二层入口：意识显化、场域精测、重塑潜意识开放体验、修炼技术开放体验、我的场域。
- 双语法律与规则入口。
- 登录用户可通过幂等接口创建真实 SASI 项目；项目与首批生产节点在同一数据库事务中写入。
- Build 八节点、Drama 十节点的初始依赖图持久化，首页可读取最近项目。
- 项目所有权来自服务端登录会话，客户端不能提交或替换 `user_id`。
- 项目附件使用短时签名上传票据进入私有隔离桶；对象路径由服务端生成。
- 小型文本与代码资产完成大小验证、UTF-8 检查、SHA-256 摘要和全文索引。
- 二进制与大型资产停留在外部深度扫描门禁，不会提前进入生产节点。
- 项目工作区可读取真实节点状态和资产安全状态。

## 受控预览 / Guarded preview

- Build/Drama 制作提案与投入边界推演。
- 本地附件只保留文件名、大小和类型；没有上传到云端，也不会执行其中代码。
- 能力中枢展示能力谱系，但不会收集外部能力凭证。
- 制作账户储备方案可见，但账本与支付回调完成前不会收款。
- 能力作品库展示授权结构，但用户编制与发布仍关闭。

## 未开放 / Not enabled

- SASI Upload Hub 的分片上传、断点续传、外部恶意文件扫描器、EXIF 清理和资产删除闭环。
- DOCX/PDF/图片/音视频/ZIP 在外部安全扫描通过后的解析与索引。
- GitHub OAuth、仓库克隆、代码沙箱、测试与部署执行器。
- 视频、图片、声音和认知能力供应商的真实调用及自动故障转移。
- 人物/场景身份板的持久化引用和跨镜头一致性引擎。
- Timeline 编辑器、字幕轨、配音轨、BGM、成片合成与导出标识。
- 生产环境应用 SASI 数据库迁移，并验证项目、节点、任务与制作账户策略。
- 支付宝/微信确认回调、制作额度锁定、结算、归还和退还。
- 外部能力凭证的加密保存、连通测试、删除与轮换。
- 能力作品隔离运行、权限清单、审阅、恶意文件扫描、授权与创作者结算。
- 生成任务队列、幂等、重试、并发限制、监控与审计日志。

## 上线顺序 / Launch order

1. 对象存储与安全上传。
2. 在目标 Supabase 项目应用并验证 SASI 数据库迁移。
3. 单一低风险能力的完整任务闭环。
4. 制作账户到账、锁定、结算、失败归还与退还。
5. Drama 身份板、故事板、镜头、Timeline 闭环。
6. Build 仓库沙箱与部署闭环。
7. 专业外部能力接入。
8. 创作者能力作品体系。

任何未开放能力都不得在前台伪装为已执行。 / No disabled capability may be presented as executed.
