# V11.50 · 灵犀场实用工具全面生产完善

本阶段不是增加“看起来能用”的入口，而是收口真实工具能力。

## 核心修复

- V11.40 preflight 因已有 `app/api/tools/pay/recover/route.ts` 而失败；V11.50 改为 reconcile 模式，不再把“文件已存在”当成错误。
- 工具页 Nav/Footer 统一由 `/app/tools/layout.tsx` 持有。
- 工具订单 `toolquote:*` 在账户订单中心单列“实用工具”。
- 支付状态支持微信 / 支付宝 / PayPal 主动恢复。
- 付款成功弹窗会主动通知原工具页，不只依赖轮询。
- 已 paid 但 grant 丢失时，用 service-role-only repair RPC 恢复。
- 本地收费工具使用 `tool_paid_jobs` 记录额度消耗与结果状态。

## 视频去水印

真实能力：
- 上传单个 / 批量视频
- 同一批应用相同固定水印区域
- 粘贴直接媒体链接
- 本地 FFmpeg delogo
- 按视频分钟付费
- 每个处理项写入 paid job

不伪装支持：
- 抖音/TikTok/小红书/快手等分享网页本身不是直接媒体文件
- 不绕过平台访问控制
- 移动水印 / 穿人物复杂水印不冒充“无痕 AI 修复”

## V11.50.2 分享页解析与定价更正

视频去水印定价统一为：

```text
¥1.20 / 开始计费分钟
不足 1 分钟 = ¥1.20
1分01秒–2分00秒 = ¥2.40
以此类推
单次封顶 ¥49
```

链接入口支持批量粘贴，最多 20 条。识别：

```text
抖音
TikTok
小红书
快手
```

解析路径：

```text
分享短链 / 分享页
→ 安全跟随公开重定向
→ 识别平台
→ 读取公开 HTML metadata / embedded JSON
→ 找公开播放媒体 URL
→ 拉入同一个视频处理工作台
```

如果某个平台页面没有公开媒体地址、要求登录、签名或额外访问控制，则明确返回“已识别平台但当前链接不可直接读取”，不伪造成功。
