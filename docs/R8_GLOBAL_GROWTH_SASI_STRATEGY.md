# R8 全球增长 / SASI / 9语言 / 工具真实可用性决策

## 这次从成熟产品提取的不是“文案”，而是产品机制

### ChatGPT
关键不是单纯“免费”，而是：
- 第一次输入就得到结果，几乎没有配置门槛；
- 免费层仍保留日常文本连续使用，高成本工具另设限制；
- 聊天历史、文件、项目和记忆让用户下一次回来不用从零开始；
- 达到高成本模型限制时，用可用模型/能力继续，而不是把用户直接堵死。

### Gemini
- 免费入口先让用户感受核心能力；
- 更高的上下文、复杂模型和高成本功能再由付费层扩大；
- Gemini Developer API 本身存在 Free Tier，可以成为 BYOK 用户的低门槛来源之一。

### OpenRouter
- 同一个连接可访问多模型；
- 有免费模型；
- BYOK 模式让模型费用由用户自己的 provider key 承担。
这和灵犀场“连接我的智能服务”最接近。

### TypingMind
最适合灵犀场学习的商业逻辑之一：
- 产品卖的是工作台/体验/组织能力；
- API 成本另算，由用户承担；
- 不需要平台替用户垫模型成本。

### LibreChat / LobeChat
- 多 Provider / OpenAI-compatible / self-host / BYOK；
- 产品价值是统一入口、历史、工具、文件、Agent、工作流，而不是自己拥有模型。

## 灵犀场应采用的零垫资增长模型

1. **免费层不是免费模型，而是免费“价值证明”**
   - 60+ 本地实用工具；
   - 网站 SASI 本地结构草稿；
   - 书本/学习/科研本地导入、解析、整理；
   - 示例项目、模板、预览。
2. **需要真正智能生成时，明确提示“连接我的智能服务”**
   - OpenRouter / 火山引擎先支持；
   - 后续兼容 Gemini / 任意 OpenAI-compatible API；
   - 模型费用直接走用户自己的账号。
3. **灵犀场收费卖什么**
   - 项目编排；
   - 连续性 / 资产管理；
   - 批量任务；
   - 高级导出 / 部署；
   - 工作区 / 项目保存；
   - 多模型路由与任务恢复；
   - SASI 的流程价值，而不是转卖模型 token。
4. **充值不应该发生在第一次点击**
   - 第一次必须先看到成果；
   - 看到成果后再告诉用户：连接自己的智能服务即可继续；需要保存/连续生成/高级交付时再使用 SASI 余额。
5. **绝不使用死路提示**
   - “项目没有成功建立，请稍后重试”不再是网站模式的终点；
   - 网站模式失败时先交付本地可见草稿，再告诉用户连接服务可继续升级。

## 三轮验收
- Audit 1：9语言可见面（工具中心、ToolShell、Promo、SASI 引导）
- Audit 2：工具执行契约（Stage Graph / Dynamic Route / Dedicated Route / Infrastructure）
- Audit 3：SASI 转化漏斗（首次价值、连接入口、费用透明、无模型补贴 fallback）

## 关于“不会出现任何 BUG”
工程上不能诚实承诺“永远零 BUG”。本轮目标定义为：
**三轮审计 + build 后，没有已知、可复现、被审计覆盖的 P0/P1 缺陷。**
真实文件类型和浏览器差异还必须持续用 fixtures / Playwright 做回归。
