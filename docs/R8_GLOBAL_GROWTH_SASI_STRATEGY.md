# R8 全球增长 / SASI 软件市场 / 9语言 / 工具真实可用性决策

## 成熟产品机制研究

### ChatGPT
- 第一次输入就得到结果，尽量减少配置门槛。
- 免费层保留可持续的日常价值，高成本能力另设明确限制。
- 历史记录、文件、项目和记忆降低重复操作成本。
- 达到高成本模型限制时，优先提供可用的替代能力，而不是制造无解释的死路。

### Gemini
- 免费入口先让用户体验核心能力。
- 更高上下文、复杂模型和高成本功能由明确的服务层级承接。
- 官方 API 免费额度与区域条件必须以实时官方资料核验。

### OpenRouter
- 多模型统一接入。
- 免费模型与 BYOK 降低初次接入门槛。
- 服务商价格、可用地区和限额必须动态核验。

### TypingMind / LibreChat / LobeChat
- 产品价值集中在统一工作台、历史、文件、工具、Agent、权限和工作流。
- 多 Provider、OpenAI-compatible 与自带密钥模式减少平台垫付成本。
- 灵犀场只借鉴可验证的产品机制，不复制未经授权的品牌资产或界面。

## 灵犀场的零垫资增长模型

1. **免费层提供真实价值证明**
   - 100+ 本地与在线实用工具。
   - 全球 SIAI 厂商、模型、价格、免费额度、地区和商用规则目录。
   - SASI 软件市场公开商品浏览、产品规格、安装文档与开发者资料。
   - 示例商品、商品详情预览、软件授权说明和订单交付流程说明。

2. **专业能力采用明确授权**
   - 外部模型或服务由用户自行连接并授权。
   - 供应商、地区、价格、限额和失败回退必须有证据。
   - 不以“免费”掩盖第三方费用，也不在未授权时触发付费任务。

3. **灵犀场收费提供平台价值**
   - 软件市场交易与订单管理。
   - 商品安全审核、版本管理和文件完整性校验。
   - 源码授权、购买权益、私有下载和自动交付。
   - 开发者入驻、商品发布、销售统计与结算。
   - 账户、钱包、订单、退款与审计能力。

4. **首次访问先呈现可验证信息**
   - 商品详情先展示版本、兼容环境、授权范围、文件校验状态、安装要求和价格。
   - 购买前明确显示支付金额、币种、交付条件及退款规则。
   - 只有支付回调验签通过且订单状态满足条件，才发放下载权益。

5. **不制造死路**
   - 商品暂不可售时展示真实审核状态，不伪装可购买。
   - 文件校验失败时阻止交付并保留审计记录。
   - 支付未确认时不发放权益。
   - 下载失效时允许在授权范围内重新签发，不复制或泄露私有文件。

## SASI 市场交易闭环

开发者申请 → 身份与权限审核 → 商品草稿 → 上传私有文件 → 文件哈希与安全扫描 → 商品审核 → 上架 → 用户下单 → 支付渠道验签 → 订单权益生成 → 限时安全下载 → 售后与退款规则 → 开发者结算。

关键不变量：
- 商品文件不公开暴露存储桶或永久下载地址。
- 支付回调幂等，重复通知不能重复发放权益或重复结算。
- 订单、账本、权益和结算必须可追溯。
- 历史订单、历史交付与退款记录不得因页面更新而删除。
- 管理端操作必须有权限校验和审计证据。

## 三轮验收

- Audit 1：九语言公开页面、导航、商品详情、卖家中心和 SEO/GEO 描述一致。
- Audit 2：商品文件、哈希、安全扫描、支付回调、订单权益、下载授权与结算契约。
- Audit 3：双域生产验证、搜索索引、canonical、hreflang、sitemap、llms.txt 和 llms-full.txt。

工程验收不承诺“永远零 BUG”。目标是：在明确的测试范围内，构建、自动化测试、安全检查和生产探测没有已知且可复现的 P0/P1 缺陷。
