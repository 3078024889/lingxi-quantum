# SASI 连续记忆与形态架构

依据用户本次两份聊天记录、实际 SASI 仓库及 `D:/二十瓦特/copernicus-twentywatts` 的定向检查。聊天中的“完整审查”“已拥有能力”和数据规模不直接当作本次已验证结论。

## 当前判断

可以实现可追溯的长期项目记忆、人物事件史、目的延续和受控工具执行。记忆增长、图关系增长、模型训练、自动改代码和通用智能是不同能力，不能用其中一项替代其余。人形适合作为状态导航：脑对应规划，记忆对应可追溯记录，感官对应输入，四肢对应授权工具，神经总线对应事件传递。

本次核对了树突模型、记忆目录协议，以及世界模型、自我模型、母版搜索、生成循环的文件存在。没有审完全部 Genesis 引擎，没有验证跨任务通用能力。实验目录明确写着 Not SASI，并禁止 Memory writers 修改 CORE-0。

## 已落地的第一层记忆

复用已有 PostgreSQL `sasi_projects`、`sasi_nodes` 与行级权限，而不是创建一套与现有产品断开的数据库。

| 数据 | 本次真实落点 |
| --- | --- |
| 谁、哪个项目 | `user_id`、`project_id`，服务端从会话验证归属 |
| 目的、决定、约束、人物、经历 | `node_type=project_memory_v1`，`input.kind/text/subject` |
| 来源、版本 | `input.source=user_explicit`、`schemaVersion=1` |
| 何时发生记录 | 服务端 `created_at`，不伪造剧情时间 |
| 更正来由 | `input.supersedes` 指向本项目旧记录 |
| 当前有效内容 | 排除被更正的旧记录，保留其历史供查看 |
| 忘记 | 删除整条更正链，防止旧版本重新生效 |
| 角色长期身份与剧情状态 | 继续复用 `cangxuan_characters`、`cangxuan_continuity_events` |
| 制作引用 | 报价绑定记忆摘要哈希；任务保存引用 ID 与版本 |

接口：`/api/sasi/projects/[id]/memory`。新增请求使用 UUID 作为幂等键；重复同一内容不重复保存，重复 ID 改内容返回冲突。写操作检查同源，读取和删除限定用户、项目和记忆节点类型。删除项目时沿用外键级联删除。删除记忆不会追溯改变已生成的作品及历史任务输入快照；后续全项目隐私清除需覆盖这些派生物。记录只用于这个项目，不自动成为他人的知识或训练数据。

界面位于已保存项目中，影像与编程项目均可使用。刷新可根据 URL projectId 恢复项目。失败时保留输入并明确告知，不能把前端显示当作云端保存成功。

这是用户明确保存的记忆，不是自动逐字记下所有聊天。现阶段达到 400 条事件时停止新增并要求整理，读取保护上限为 500 条事件；超过上限要求整理，不静默遗忘早期目的。模型上下文仍有长度限制，过长时拒绝开始任务，不能截断关键约束后继续收费。数据库没有被宣传为无限存储。

记忆内容始终是用户参考数据，不能授予支付、工具或管理权限。CORE-0 的独立数据库角色和治理流程尚未实现，本次没有将用户目的记录冒充不可变宪法层。

## 树突实验复核

运行实际 `engine/dendritic_neural_model.py` 的 `train_xor`：输入 2、分枝 4、训练 400 轮、种子 0–9。五个种子达到训练集 XOR 四题全对，其余五个为 75%。这是对四条训练样本的拟合检查，不是泛化测试、意识测试或工程产品验收。

代码 `watts()` 明确标注 Proxy，不是真实功耗计。不能从输出的 watts 数值推断已实现二十瓦特智能或脱离硬件。

本次实现 `continuityEvidence` 的三分枝条件检查：身份、前态、当前事件共同具备才就绪。这是工程上的证据联锁原语；尚未接入视觉模型验片，也不等同于训练出来的生物神经元。

## 下一阶段真实建设顺序

1. 显式对话保留开关、原始事件引用、个人/项目权限、导出与清除；避免把推测自动写成事实。
2. 事件事务与 outbox、失败重放、处理器版本和幂等消费；再让多个模块共享事件。
3. 知识节点与关系边，证据来源、矛盾记录、候选/已验证状态；向量检索只负责召回，不决定真实性。
4. 角色图像与声音引用、连续性验片、按集镜头合成。数据库记住脸型并不保证视频模型不换脸。
5. 隔离编程执行器，修改前加载项目目的，测试后记录结果与依据。
6. 修复候选在沙箱中运行回归评测；只批准有证据的能力变更。学习进程不持有生产部署或 CORE-0 修改凭据。
7. 最后由真实事件、器官健康与验证结果驱动人形视图；缺少数据的器官显示未接通，不伪造脉冲与成长数值。

## 模型成长与 SASI 记忆的区别

OpenAI 官方说明，模型训练从公开信息、授权合作资料及人工提供或生成资料中学习模式，主要通过调整参数形成能力。它与 SASI 的逐条项目记忆不是同一层，也不意味着某个助手保留了跨所有模型世代的个人经历。参考：https://openai.com/policies/how-chatgpt-and-our-foundation-models-are-developed/
