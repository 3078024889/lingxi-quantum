# R19 全球能力对标与真实媒体质量闭环（2026-10-09）

## 已在 main 上证实的事实
- R18 已引入官方 `@contentauth/c2pa-web` 的 `Reader.fromBlob`、Wasm 浏览器验签和独立的 C2PA 结果栏目；真实有凭证/无凭证/被修改样本已进入浏览器门禁。
- AI 图片分类是有误差的模型推理，**不等于凭证签名结果、真实来源概率或真实性保证**。
- 截至 R19 的本轮审核，视频是采样画面分类（此前 3 帧，本轮扩展至 7 帧）；不覆盖逐帧时序或音频。
- 人声检测只分析音频开头 12 秒，不能保证适用于任意音乐、语言、克隆器或完整录音。
- `pricing-policy.json` 中两项 AI 检测仍处于 `disabled-quality-gate`；不得仅因 C2PA 实现完毕而收费。

## 从成熟体系提炼的优势

| 对标研究或开源平台 | 能直接复用的成熟优势 | SASI / 灵犀场具体采用与限制 |
| --- | --- | --- |
| CAI / `c2pa-web` | 浏览器 WASM 读取验证、信任链与来源声明分离、正式 Reader 生命周期 | 保留 R18 官方 SDK；签名有效不代表内容一定真实，无凭证不代表 AI 生成 |
| DeepfakeBench | 统一测试协议、不同模型与数据集的可比较性、发布权重 | 制定统一 FPR、TPR、AUROC、EER 与按编辑/压缩程度分层评测；未做测量前不宣称准确率 |
| DF40 (NeurIPS 2024) | 跨 40 类伪造技术、跨生成方法泛化测试 | 建立 seen/unseen generator 分层，不能用单类生成器结果代表全部 |
| Deepfake-Eval-2024 | 多网站、多语言、真实流通素材的评测 | 评测必须包含社媒二次压缩、剪裁、转码、真人内容与未知合成 |
| FFmpeg | 成熟媒体解码、探测与可重复时间轴抽样 | 大文件与全片检测须用独立异步任务/媒体工作者；浏览器轻量预览不冒充全片分析 |
| OpenAI Agents / Vercel AI SDK | 统一工具调用与状态驱动呈现 | 媒体工具输出结构化证据，再由 SASI 承接会话、解释边界；不在工具页面复刻第二套智能体 |
| Temporal / Inngest / Supabase | 可恢复任务、幂等、持久化记录 | 以后收费媒体全片任务沿用现有事务、幂等与结果存储，避免另起异构系统 |

## R19 本轮实际变更
1. 视频示例分析由 3 个分散点调整为 7 个分散点，不改变现有 80 MB 浏览器处理限制。
2. 视频页面更新中英双语范围说明；无基准测试前不称“全片 AI 真伪分析”。
3. 生产 CI 新增媒体能力证据门禁：保证采样范围及页面披露一致、C2PA 与 AI 模型结论分离、收费仍关闭。
4. 不新增大型推理模型，不增加服务端视频开销，避免把 2GB 主站变成媒体 GPU 推理机器。

## 尚未完成，不得宣称已闭环
- **图片**：独立真实标注数据、已知/未知生成器、真人/AI 编辑/全 AI 生成三分类、阈值校准、压缩和编辑后的误判率，尚无正式验收报告。
- **视频**：完整时序检测、帧间一致性、镜头切换与视频声音联合分析、覆盖率与异步任务/断点续跑，尚未上线。
- **音频**：音频全段分窗、静音和噪声过滤、不同语言与克隆模型泛化验证，尚未上线。
- **C2PA**：仍需对信任名单更新失败、远程凭证、证书吊销、超大文件与老设备进行持续性回归；R18 已覆盖部分真实样本，不代表一切格式都支持。
- **收费**：真实账户与 IP 防刷、三次/日免费额度服务器原子领取、重复请求防重、失败不扣/退费、支付、对账、安全隔离、隐私和申诉，都必须通过端到端验收才解锁。
- **SASI 总控**：证据链结果进入项目会话与持久任务、统一解释与追问体验，需要后续独立 E2E。
- **微信小程序**：源码索引允许不等于微信实际收录，实际搜索曝光必须以微信后台和真实微信端证据为准。

## 计费红线
签名验证是凭证事实验证，不按“AI 检测准确率”销售。仅 C2PA 验签成功不能触发 AI 模型分析的计费状态变化。任何下游商业开关必须绑定经过回测的分析套餐、服务端交易门禁、核对过的价目及失败保护。
