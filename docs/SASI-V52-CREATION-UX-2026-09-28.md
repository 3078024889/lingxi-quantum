# 灵犀场 SASI V5.2 创作入口重构

基线：`1f01b470ce77df147457597be50da580b28f07c2`

这轮不是再堆一张“功能卡片”，而是把短剧和网站构建入口改成统一的 ChatGPT / 豆包 / 千问式创作界面。

## 这轮完成

- `/sasi/drama` 改为单一对话式创作入口
- `/sasi/build` 改为单一对话式网站构建入口
- `+` 添加附件
- 整个输入框支持拖入文件
- 项目附件真实上传到现有 SASI Storage
- 上传后真实执行文件检查
- TXT / MD / JSON / CSV / YAML / PDF / DOCX / PPTX / XLSX / EPUB / ODT / 代码 / 图片 / 音频 / 视频
- PDF / DOCX / PPTX / XLSX / EPUB / ODT 增加服务端文本提取
- “连接创作服务”按钮直接进入 `/sasi/connections`
- 修复 ConnectionCenter 与后端 `provider` 参数不一致的问题
- 短剧清晰度 UI：720p / 1080p / 2K / 4K
- 通用画幅 UI：9:16 / 16:9 / 1:1 / 4:3 / 3:4 / 3:2 / 2:3 / 21:9
- 不支持的 2K / 4K 或画幅不收费、不假装成功
- 网站在没有外部生成服务时，仍可用确定性规则生成本地可下载起稿
- 项目创建、素材上传、本地网站交付都会写 V5 学习信号，因此“测试学习”不依赖外部 AI API

## 学习如何在没有 API 时测试

新的创作入口执行以下任一动作都可产生真实 V5 telemetry：

1. 建立短剧或网站项目
2. 上传并保存附件
3. 无 API 生成本地网站起稿
4. 继续一个已建立的项目

这类学习记录的是产品/运行信号，不是把用户文件内容拿去做全局训练。

## 不做假的部分

- 2K / 4K 只有真正通过生产路线质量验收后才允许生成。
- 4:3 / 3:4 / 3:2 / 2:3 / 21:9 可以成为项目规格，但当前视频 Provider 若未验证该规格，会明确提示不可用，不产生费用。
- 短剧最终生成仍需要平台托管 Provider 或用户自己的已验证连接。
- 本地网站起稿是确定性页面起稿，不冒充高智能生成；连接创作服务后可继续生成更完整版本。

## 设计原则

输入是主角，不再让用户先理解模型、Provider、任务节点和复杂流程。
技术设置收进“连接创作服务”和规格选项里。
