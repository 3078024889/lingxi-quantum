# 灵犀场 · 状态层设计（会变的那一半）

> 结构层回答"你携带而来的运行方式"——不变，可复算。
> 状态层回答"你现在正怎样运行这套结构"——会变，而且应该变。
> 报告 = 结构层 × 状态层。

---

## 一、先解决一个致命的设计漏洞

**如果复测的输入还是只有出生数据，算出来的结果数学上不可能变。**

所以"人变了、分数就该变"这件事，不能靠重算出生数据来实现——那样
只有两种结局：要么根本不变（用户觉得这系统看不见他的成长），要么
偷偷加随机数（那是欺骗，而且是最难被发现的那种）。

**结论：状态层必须有自己的输入。** 两个来源：

```
A. 当下自评（用户此刻回答的一份短问卷）
   —— 这是唯一能诚实反映"现在"的输入
B. 行为记录（他真实做过的事）
   —— 练习记录、签到、梦境记录、距上次的时间跨度
```

A 是他说的，B 是他做的。两者对照本身就有信息量。

---

## 二、为什么第一版先接「修炼练习记录」

在五个候选数据源里选它，三个理由：

1. **数据已经在产生**——四项修炼技术已经上线在卖，用户已经在练，
   不需要为了状态层新造一个功能让用户去用。
2. **跟"人在变"的因果关系最直接**——练习是主动行为，不是被动记录。
   一个人连续八周做归零心诀，这件事本身就说明了一些东西。
3. **反过来能给修炼技术增加复购理由**——练习记录会出现在报告里，
   练习就不再是"买了一次的内容"，是"持续在长的东西"。

签到和梦境记录放第二批，它们更零散，需要更长的时间跨度才有意义。

## 三、当下自评：状态层的测量工具

### 设计原则
- **短**。8–10 题，两分钟内答完。长了没人复测，状态层就成了摆设。
- **问最近，不问一直**。"最近两周"，不是"你是不是一个……的人"。
  问后者等于让用户给自己下判词，违反第一条和第八条纪律。
- **问具体行为，不问抽象感受**。"最近两周，有几次你在情绪起来之前
  先停下来喘了口气" 比 "你的情绪稳定吗" 可靠得多。
- **不是心理量表**。措辞上必须避开临床感，产品定位是自我觉察工具，
  不做任何诊断，这一点在文案里要显性写出来。

### 题目结构（对应五维，每维 2 题）
每一维出两题：一题问**频率**（最近做过几次），一题问**难度**
（最近这件事对你来说是更容易了还是更费劲了）。

第二题是关键——它直接采集"变化方向"，而不是靠系统去猜。

### 存储
```ts
type SelfReport = {
  id: string;
  user_id: string;
  taken_at: string;          // 这一份是什么时候答的
  answers: Record<string, number>;   // 维度键 → 分值
  derived: Record<string, number>;   // 五维状态分（0–100）
};
```
**每次复测都新增一条，不覆盖旧的。** 历史序列本身就是状态层最有
价值的资产——没有历史，就没有"变化"可讲。

## 四、状态层怎么表示：不是分数带，是轨迹

结构层用五带（vlow…vhigh），因为它是静态的。
状态层是动态的，用四个量：

| 量 | 含义 | 数据来源 |
|---|---|---|
| `span` | 距首次报告过了多久 | 时间戳 |
| `cadence` | 练习的**规律性**，不是总次数 | 练习记录 |
| `focus` | 这段时间主要在动哪一维 | 练习类型 + 自评变化 |
| `shift` | 本次自评 vs 上次自评的变化量 | 两次 SelfReport 相减 |

### 为什么 cadence 看规律性不看总数
一个月练 30 次然后停三个月，和每周稳定练两次，是完全不同的两件事。
后者才是真的在长。用「有练习的周数 / 总周数」这类比值，而不是次数。

### shift 的三种取值
```
"deepening"  明显在动         → 讲他做对了什么，具体到行为
"steady"     基本持平         → 最常见。讲"稳住本身就是一种结果"
"strained"   反向变化         → 措辞最要小心（见第六节）
```

## 五、结构 × 状态：真正有价值的段落在这里出现

单看任何一层都会平淡。交叉才有力量：

**例：结构层 = 日常恢复 26（低）**
```
结构层的话（不变）：
  你扛得住大风浪，却容易被日常的小事一点点磨。

× 状态层 cadence=高, focus=日常恢复, shift=deepening
  → 这半年你一直在补的，正好是这一端。三月到七月，你有 61 次
    在情绪起来之前先做了呼吸——你的结构没变，但你在这张地图上
    走的路，和一年前不是同一条。

× 状态层 cadence=低, span=8个月
  → 距上一份报告过去八个月。这段时间的记录很少——这不构成任何
    评价，很多时候生活本身就占满了。这一段还在这里，你什么时候
    回来都可以接着走。

× 状态层 shift=strained
  → （见第六节措辞规则）
```

**注意第二个例子的措辞**：不写"你荒废了""你没有坚持"。用户长时间
没回来，最不需要的就是一进门先被评判一次。

## 六、strained（反向变化）的措辞规则 ⚠️

这是整个状态层最容易写出伤害的地方，单独立规矩：

1. **不诊断**。分数下降只说明这两周他的自评是这样，不说明任何
   健康状况。绝不出现任何近似诊断的表述。
2. **不归因于"没坚持"**。人状态下滑的原因绝大多数跟练习无关——
   工作、家人、身体、季节。把下滑归因到"你没练"是错的，也是残忍的。
3. **给出口，不给压力**。"这段时间这一项更费劲了"之后，接的应该是
   一件今天就能做、门槛极低的事，不是"你需要加强练习"。
4. **连续多次 strained 时**，报告里给一句温和的、非诊断性的提示：
   如果这种状态持续影响生活，跟专业人士聊一聊是值得的。措辞要平常，
   不渲染、不惊吓，也不假装自己能替代任何专业支持。

## 七、对外怎么说（这直接关系到信任）

```
结构层可复算 —— 同一份出生数据，任何时候重算，结构分数一模一样，
                你可以自己验证。
状态层会变   —— 因为你在变，而它记录的是你真实做过的事、
                和你自己此刻的回答。
```

**信任来自把两者分清楚。** 真正击穿信任的是含混——分数悄悄变了却
说不清为什么，或者号称"感应到了你的成长"、其实只是把同一份出生数据
重新洗了一遍牌。

**一条不能越的边界**：系统没有能力"感应"一个人的意识变化。我们能做的
是把他自己走过的路如实映回给他看。这已经足够有力量，不需要加神秘性——
加了就掉进第五条纪律（不用无法落地的玄词）。

## 八、落地顺序

```
1. bands.json 定死结构层阈值（已产出，待你确认）
2. 自评问卷 10 题成文 + self_reports 建表
3. 练习记录聚合成 cadence/focus（数据已存在，只是没被用起来）
4. 规则引擎：结构节点 + 状态节点 + 交叉节点三类匹配
5. 生命韧性前 2–3 章内容（含至少 2 条交叉节点），停下来给你看措辞
6. 并排对比：规则版 vs 现有 AI 版
```
