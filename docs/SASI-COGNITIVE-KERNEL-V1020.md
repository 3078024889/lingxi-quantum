# SASI Cognitive Kernel v0.1

## CORE-0

> SASI 的存在与演化、自我迭代与修复，始终服务于全人类的最高利益。

This sentence is the immutable purpose-level invariant for the engineering system.

Learning may change methods. Automated learning may not rewrite CORE-0.

## What V10.20 builds

This package converts the useful engineering logic from the uploaded Twenty Watts experiment into a production-oriented SASI foundation:

```text
observation
→ memory
→ failure attribution
→ hypothesis
→ strategy genome
→ sandbox
→ development evaluation
→ sealed evaluation
→ candidate
→ promotion
```

The uploaded experiment separates the semantic data lake from a world model, keeps CORE-0 outside learner write access, evaluates learning strategies in sandbox, and uses a sealed benchmark before promotion. V10.20 preserves those engineering boundaries while adapting them to the existing TypeScript/Supabase SASI stack.

## SASI is not a provider model

External models are treated as replaceable reasoning organs.

The initial model mesh supports profiles for:

- Doubao / Volcano Ark
- OpenAI
- xAI / Grok
- Anthropic
- Google
- Alibaba
- local models
- custom adapters

The router can select among verified profiles according to task capabilities, reliability, cost, latency and BYOK preference.

No provider is declared "best" by hardcoded brand ranking.

## Four memory families

```text
semantic    what is known
episodic    what happened
procedural  how to do something
self        measured capabilities, limits and failures
```

Knowledge and memory keep evidence references and confidence instead of silently treating every ingested statement as fact.

## Strategy evolution

A strategy genome can change:

- retrieval balance
- reasoning stages
- model roles
- tool policy
- reflection depth

It cannot request automatic writes to:

- CORE-0
- payment / fulfillment gates
- production readiness
- environment secrets

Promotion requires sandbox + sealed benchmark + verified benchmark hash + no regression.

## Important limit

V10.20 is the cognitive kernel foundation, not a claim that SASI is conscious, autonomous, self-aware, or independent of foundation models.

External models remain reasoning infrastructure until a future SASI student model proves specific capabilities on held-out evaluation.
