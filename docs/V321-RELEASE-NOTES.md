# V321 发布说明

## 微信小程序上传版本

- 版本号：`3.3.0`
- 版本备注（可直接粘贴到微信开发者工具）：

> 重构生命原型八流汇聚：严格校验 365 天内八项有效场域档案，关系共振三类任一完成计入一条支流；新增可打开的八流进度、已解锁/未解锁状态、明确返回入口与 22 页生命原型档案。十类 24 题精测升级为 24 条多题证据报告条目，并优化网页报告导航、账户归档及 PDF 分页排版。

## 产品边界

- 官网生命原型：从出生日期、具体时刻、历法与天文位置进入，生成长期本源原型矩阵。
- 小程序生命原型：从 365 天内八条生命支流进入，生成当前八流汇聚原型。
- 两套入口共享 64 枚原创原型视觉资产，但不共享算法、报告骨架或进度语义。

## 自动生成规则

生命原型仅在以下条件同时成立时生成：

1. 用户本人已登录，且八项产品均存在有效权限或在审计授权清单中。
2. 365 天窗口内已完成生命图谱、关系共振、生命韧性、桃花磁场、财富创造地图、今日潮汐、生命镜像、生命灵签。
3. 关系共振的深度关系、合伙商业、其他关系任一完成即计入一条支流；完成多类只增加证据，不增加支流数量。

旧版 `lingxifield-dendritic-v2` 生命原型不会再作为当前报告复用；满足条件后会生成 `lingxifield-mini-archetype-v3` 新档案。普通用户仅有解锁权限或仅完成部分产品时不会自动生成。

## 数据库

本版本沿用 `mini_dendrite_assessments` 现有 `jsonb` 结果与 `algorithm_version` 字段，无需执行新 SQL。
