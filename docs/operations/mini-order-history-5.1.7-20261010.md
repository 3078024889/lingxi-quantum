# 小程序 5.1.7 旧订单与新充值

- 根因：充值页只要存在本机 pending orderId，就始终查上一笔订单，没有独立新充值入口。
- 增加“保留旧订单，开始新充值”：确认后仅释放本机当前充值槽位。旧订单、后续查单及后台财务记录保留。新付款需再次主动确认金额，并生成新的 requestId。
- 订单页增加“移入历史”“恢复显示”，偏好存于本机，不删除后台记录，也不冒充微信已取消订单。移入当前充值订单会释放本机充值槽位。
- 保留结果未知且尚无 orderId 的请求身份，避免网络失败后的重复创建。
- 微信确认关闭且未付款才显示已取消；未知结果和已付款记录不能直接当成取消。
- 中文化订单名称、状态和金额，修复全宽按钮挤压标题的移动端布局。
- 测试：mini-topup-client、mini-order-history、mini-closed-order-recovery、mini-api-recovery、audit-mini-program 全部通过。
