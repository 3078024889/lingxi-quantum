# 手机字幕翻译

原字幕页面只调用浏览器 `Translator`。根据 [Chrome 官方说明](https://developer.chrome.com/docs/ai/translator-api)，该接口仅适用于桌面浏览器，手机不能依赖它。原实现还把 WebVTT 文件头、NOTE 元数据当普通文字翻译，可能破坏文件格式。

本次为不支持设备翻译的浏览器提供明确的“在线生成翻译预览”入口，使用既有 `/api/tools/document-translate` 账户体验服务，仅发送字幕文字；需要登录，额度耗尽或服务失败即停止，没有自动付费重试。具备设备翻译能力的桌面仍可使用原方式，也能主动选择在线方式。原字幕导出每 5,000 字符 ¥1 / $1 的规则保持。

SRT/WebVTT 的文件头、NOTE/STYLE/REGION、字幕标识、时间轴和定位设置保留原值，只有字幕正文进入翻译。翻译返回缺段、改变样式标记、乱码或插入时间行时拒绝成功导出；按批次请求，支持停止。付款前保存文件、语种、译文与模式，完成结果可保存及发送，复用统一的原文件字节。

新增真实函数隔离测试覆盖分段、时间轴、格式标记、批次、取消与错误；浏览器测试覆盖手机兼容路径、登录失败、残缺结果、样式破坏、设备内翻译、原价报价及保存/发送。此文记录待验证的实现，不预先声明最新提交已经通过。模型响应与付款均隔离，不代表实际翻译质量或真实支付已验收。
