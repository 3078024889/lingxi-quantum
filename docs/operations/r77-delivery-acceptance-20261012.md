## 当前源码修复

- 官方 OpenAI 视频能力按 [官方退役公告](https://developers.openai.com/api/docs/deprecations)退出新任务选项。第三方兼容连接独立核验，文字能力保留。删除旧平台供应商的官方 OpenAI 视频提交、查询、下载和默认模型分支。
- 供应商成功状态不再等于交付成功。图片通过实际解码；MP4 通过容器、时长、分辨率与隔离 WASM 逐帧解码。文件写入私有 R2 或既有 Supabase Storage，再取回验证字节数和 SHA-256，生成拥有者限定的作品 ID。
- 作品归档记录是结算前置条件。图片和视频原有余额预留、费用扣除、任务成功在 PostgreSQL 事务内完成。并发确认与完成不能重复调用生成或重复扣费；保存失败时余额预留及扣费回滚。文件无效时释放预留，平台不收费；供应商账单由供应商结算。
- 保存重试使用已持久化的供应商回执，不再次生成。公开视频地址已取得后，恢复归档不依赖已经变化的连接配置。需鉴权的兼容视频只能使用原连接凭据，重定向不转发凭据。
- 原生 Worker 与实际 TypeScript 客户端共同签名完整路径和 owner 查询，防止查询/取消签名失配。请求体流式限制 1 MiB。
- 免费路由保留七日实测健康信息，每日配额仍按当天计算。OpenAI 兼容调用在服务端流式消费，包括不向浏览器推送增量的调用。首字限时 12 秒，完整回答总预算 150 秒，相关函数与后台 Worker 上限 180 秒，回答有字符上限并必须完整结束。
