# 每日导出额度与文件交付

本次规则依据用户最终确认：每个原免费工具每天免费五份，同时检查 IP 与账户；每天北京时间零点重置，超过后每份 ¥1 或 $1，保留两个独立币种价格。原有付费工具不改为此价格，PDF 永久脱敏另按用户明确要求每页 ¥1 / $1。批量视频链接每次最多五个，不静默丢弃超量输入。

## 实现

新增服务端事务记录每日 IP／账户免费份数及具体结果的导出请求。用数据库时间计算日期，以事务锁处理同一工具当日并发请求；免费份数取两侧剩余额度的较小值，混合批量只为超出的份数报价。已有请求绑定工具、账户或原 IP、原始数量；重复请求不重复分配。

共用的保存、发送、ZIP 和部分文字复制入口接入导出权限。ZIP 按成员结果数计算，当前页面已获授权的成员不再收费；取消后重试固定原请求与成员组成，避免改变数量或重复支付。直接链接下载的异常兜底也必须通过权限检查。二维码链接下载缓存同一结果 Blob，重复保存不新建额度请求。部分混合付费入口保留原权限体系，包括 PDF 转表格的既有 OCR 付款路径和阅后即焚文件。

通用超额导出复用现有报价、付款和导出授权消费，报价由服务端核对原请求、账户、数量和草稿。每份两个币种均为 1，价格不符合要求时拒绝报价；匿名转登录通过同一事务认领并关联账户份数。文件保存在本机草稿，付款在独立窗口进行，阻止弹窗时可通过草稿恢复。结果准备和授权消费后才继续官方保存／发送，不自动扣款。

额度实现不出现在日常操作说明中；需要付款时显示确认入口及支付页金额。底部重复的“输入与输出／处理方式”和格式代码改为九国语言教程与常见问题；移除文档转换中的 OPF、XML 实现细节。每日体验标记替代无条件免费宣传。临时邮箱原先单独的每日十个免费入口按要求改为五个，原有付费批量价格保持。临时邮箱 CSV 不再叠加通用导出收费，避免已付费批次再次付费；其额度由创建邮箱的服务端原子事务管理。

## 实际边界

导出额度保护官方保存与发送入口。浏览器已经生成的内容不能依靠前端机制承诺无法被开发者工具读取；不能把它宣传为服务器端文件加密交付。浏览器内实时预览、手动选中文字及未接入共用入口的混合在线操作需要逐项继续验证。每个 IP／账户的限制也不等于识别同一自然人所有匿名设备。

微信分享交接并不代表朋友已经收到。来源与交付限制详见 [文件交付记录](./file-delivery-runtime-20261015.md)。2GB ECS 没有实际容量或并发压测结果，不能声称足以承载视频模型或常驻浏览器代理。新视频能力复用外部智能服务，未在 ECS 安装大模型；没有付费生成调用。

## 混合工具的补齐

二维码 PNG/SVG、通用二维码、UUID/ULID、图片与视频去水印、证件照、字幕翻译、手写识别 DOCX 和临时邮箱 CSV 接入同一文件发送入口，保留原保存按钮名称。二维码 SVG 不再反复创建短时对象链接；保存与分享复用同一份 Blob。

阅后即焚文字与原有付费附件分别处理：仅文字创建按 IP／账户每日五份，之后每份 ¥1 / $1；文件上传保留原价格。超额文字的加密草稿及解密密钥只存本机，付款返回恢复创建链接，不能把秘密草稿当普通 JSON 下载。服务端 `create_metered_burn_note` 将每日额度、创建与收据放在一个事务；同一请求重试不延长有效期或重复创建。内容焚毁后只保留完成时间与密文参数的 SHA-256，旧请求不能重新生成已销毁内容。

该迁移远端版本 `20261015235007`。真实 PostgreSQL 回滚测试通过：前五份、第六份阻断、完全相同的重试、不同参数、销毁后重放、原 IP 绑定及匿名/普通账户不能直接执行 RPC。所有测试行回滚，未产生任何付款。新增浏览器测试核对付款返回后实际 AES 解密内容，以及没有秘密草稿下载。
