# 2026-10-13 十轮工具审计与修复

范围：当前主仓库的 121 个公开工具，91 个专用页面、30 个共享页面。三份目录去重后没有缺失页面；109 项声明在浏览器处理。分类为图片 25、PDF 38、媒体 7、字幕 6、文本 15、隐私 10、表格 6、文件 7、识别 7。

本轮是十个不同维度的源码、差异和行为审查，不是重复运行十次同一个脚本，也不代表逐工具的所有格式、设备和供应商都完成真实输出验收。未使用用户供应商额度，未充值或开通 Seedance 2.5。

逐工具清单、源码依赖、可找到的具名测试、参考项目和待验证项见 [comparison.csv](v79-tool-audit/comparison.csv)、[inventory.json](v79-tool-audit/inventory.json)。初扫 67 项未找到名称直接对应的行为测试，新增用例后为 64 项；共享路由测试存在，不能据此推断这些工具完全没有测试，也不能把页面可打开等同于结果正确。
