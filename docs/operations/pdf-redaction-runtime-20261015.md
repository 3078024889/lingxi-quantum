# PDF 永久脱敏与付费交付修复

本次使用合成的两页 PDF 和图像进行真实浏览器操作，未使用或上传用户截图中的私人文档，未进行真实付款。

## 实际复现

旧构建的浏览器记录显示：默认自带一个遮盖框，背景为 `rgba(0,0,0,0.75)`，画布 `touch-action:none`，两页文件发出的报价数量仍为 `1`，401 登录失效没有恢复链接。线上价格表确认为每份文件 ¥2 / $2。这些观察记录保存在本机 `redaction-baseline.json`。

## 最终行为

- 默认滑动浏览，用户主动点击框选后绘制一处，松手返回浏览；支持多区域、撤销、清除和逐页保留。
- 预览为完全不透明黑色。支持只遮盖指定页的区域，也支持所有页面相同位置；全部原始页面保留在导出文件中。
- 免费预览，按导出的文件总页数计费，每页 ¥1 / $1，两页即 ¥2 / $2。CNY 与 USD 使用独立价格表。
- 重新渲染并以无损 PNG 构建新 PDF；不携带原文层、原始附件、批注、书签或文档元数据。纸张尺寸保留。
- 显示处理进度，失败时保留已付任务的重试状态。表单项与文件在处理中禁用，防止任务参数变化。

修复在原组件中替换旧逻辑，不再保留旧单框实现或半透明预览；原路由直接使用新实现。数据库历史迁移保持不变，新增价格迁移记录本次变更，避免破坏历史部署。

## 同类问题

隐私截图工具存在同样的手机滑动误画问题，一并改为默认浏览、明确框选和自动返回浏览，增加九国语言文案。黑块用于敏感内容，模糊与像素化只描述为视觉效果；模糊输出限制在选区内，不改动选区外像素。

发现批量 PDF、音频降噪、手写识别、PDF 转 Word 在开始处理时会卸载支付组件，丢失付款完成或失败重试状态。改为保留组件并暂时禁用，验证输出与失败重试，而不是重新报价。PDF 转 Word 的 OCR 失败路径也补充释放页面画布和 PDF 实例。

共用的两类付款按钮现在能明确处理 401，提供新窗口登录链接，保留当前编辑页面。未绕过真实认证、订单归属或收费校验。

线上付费目录逐项比对价格表时，发现 `image-translator` 行缺失。按既有迁移 `20261001165000_media_production_pricing_v19.sql` 恢复原价 ¥0.99 / $0.29，保留任何已存在的管理员覆盖。供应商服务准备检查仍然生效，未因恢复价格而绕过服务就绪校验。

## 验证与范围

浏览器用例实际上传、框选、切页、导出和重新打开文件，覆盖桌面与手机视口。另用独立 PyMuPDF 检查导出文件：敏感区域黑色像素、原始纸张尺寸、无可提取文本、无字体、无附件、无作者与 XMP；单页遮盖和全页同位置处理的覆盖范围分别断言。

付费路径使用拦截的测试报价与付款状态，真实执行客户端文件处理；没有扣余额、调用支付供应商或修改真实订单。实际微信 iOS 内置浏览器与原生小程序支付尚未真机验收。真实视频与翻译模型的最终质量不能由这些文件处理测试推断。

交互研究参考 [Adobe 的永久脱敏流程](https://experienceleague.adobe.com/en/docs/document-cloud-learn/acrobat-learning/advanced-tasks/protect/redact)：先明确选择区域，再应用并保存；不复制其私有代码。供应商视频接口另外核对 [Volcengine](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[xAI](https://docs.x.ai/developers/model-capabilities/video/generation)、[Aliyun](https://www.alibabacloud.com/help/en/model-studio/text-to-video-api-reference) 官方异步协议；缺失服务或回执不产生替代动画成片。
