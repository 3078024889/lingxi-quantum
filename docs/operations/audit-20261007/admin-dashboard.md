# 管理后台与余额消费可见性

入口：`/account/money-admin`。管理员侧栏显示“管理后台”。沿用余额页面的横向栏目、蓝色资金总览、圆角面板与明细表。

- 总览：人民币、美元分别汇总；渠道支付记录包含充值，余额支付订单另列，避免重复算收入。渠道账单才是银行到账依据，后台汇总不是净利润或结算余额。
- 订单：所有用户的历史订单，25 条一页，可按邮箱、用户编号、订单编号、工具名称搜索，支持支付方式和状态筛选。详情显示支付时间、原币种、渠道交易编号和余额支付路径。微信小程序支付单独标识。
- 用户：注册时间、最近登录、邮箱验证状态与订单数量，支持分页和进入用户订单。排除匿名和已删除账户。
- 访问：7 / 30 / 90 天的浏览次数、按日匿名会话、每日趋势、页面、来源、域名与设备。北京时间分日。只采集公开页面，不记录账户身份、原始 IP、查询字符串、提示词或私人项目路径。遵守 DNT / GPC，过滤常见机器人。上线前无历史数据，不能追溯昨日访问量。广告拦截、隐私设置及限流可能造成低估。
- 退款与提现：保留原单查询、商户资金不足提醒、邮件重试与发送记录。申请列表明确标注最近 100 条。余额支付、支付订单和注册使用站内后台动态；没有新增外发邮件。
