## 修复和对照

- JSON 工具原来 parse/stringify 会改变大整数、负零和指数写法并丢失重复字段。新实现仅验证 JSON 语法并重新排列源码 token，保留原始数字、字段和转义，限制输入、嵌套和输出。参考 Microsoft 的源码扫描/排版原则，没有整体复制实现或新增依赖：<https://github.com/microsoft/node-jsonc-parser/blob/main/src/impl/format.ts>。
- 文本计数实际结果补齐九语言标签，保留中文默认调用契约；验证真实中文、emoji、换行、英文词和 UTF-8 字节。大小写转换的格式切换及输入保留完成浏览器验证。
- C2PA 测试不再每次读取可变 main 的在线样本。官方仓库版本固定为 `d00ffc9ab9bf66170d96d81120a231aa241372c3`，三个图像/视频样本与许可证保存在 tests/fixtures/c2pa-official，manifest 记录来源、大小和 SHA256；测试读取时先验证哈希。真实 SDK 和签名判定保持，未模拟 SDK、未接受 unavailable/invalid 为签名通过。
- R75 再核查：客户端签名包含 owner 查询，当前 Python Worker 已同样签署完整路径和查询。实际 TypeScript 请求由实际 Python 验证，并检查篡改、重放、过期及流式大小，不能仅凭客户端表达式判定仍存在旧问题；没有宣称未知 GPU Worker 部署已验证。
- 删除未被引用且要求废弃 tabBar 的 v41-miniprogram-sync 检查；保留仍用于已发布链接兼容的页面。

121 个公开工具的目录、依赖和对照表沿用并更新 V79 清单。61 项仍没有名称直接对应的浏览器行为测试；已有共享模块与路由测试，不能把该数字当作无测试，也不能把回归通过当作所有格式完全保真。
