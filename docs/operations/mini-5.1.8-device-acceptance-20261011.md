## 实际改动

- 待确认充值从创建时间起计时五分钟，到期释放本机 checkout，不再占住新充值入口。旧版 requestId 中原始时间用于旧记录迁移；未知年龄不伪造到期。
- 当前订单列表中 pending 充值单满五分钟自动移至历史视图，付款确认后不再受此过期过滤影响。后台财务记录和回调匹配仍保留，不物理删除结果未知的订单。
- 页面展示期间计时，离开停止；重新进入根据原始时间重新计算，不重置五分钟。
- 账户 web-view 使用已登记业务域名 lingxifield.cn；不再把 API 请求域名 mini-api.lingxifield.cn 用作网页业务域名。

- 合并并发登录；付款先完成身份登录再获取支付所需的新微信 code，避免后续登录交换另一份 code。
- 账户绑定错误显示实际服务端错误或连接分类，不再统一掩盖成“请稍后再试”。

## 真机验收

1. 打开新体验版，检查账户连接/绑定网页及返回。
2. 测试10元与自定义整数、两位小数付款入口，取消时记录明确提示。
3. 一笔未付款充值保留五分钟，确认自动退出当前流程且能新建充值，历史仍可查。
4. 若实际扣款，核对订单、余额、通知三个结果；未知结果不得当成充值成功。
