## 研究与取舍

- [pdf-lib](https://github.com/Hopding/pdf-lib)：MIT；浏览器生成、修改 PDF 与透明 PNG 嵌入。继续使用已有依赖，不增加第二套 PDF 服务。
- [PDF.js](https://github.com/mozilla/pdf.js)：现有浏览器阅读与页面渲染。表格转换依据真实定位文本；扫描件不能假装已完成文字识别。
- [signature_pad](https://github.com/szimek/signature_pad)：研究平滑笔迹、透明背景和输入采样。当前新增签名画板在现有 React 界面中实现，没有整包复制第三方代码。
- [MarkItDown](https://github.com/microsoft/markitdown)：MIT；作为文档结构提取方案参考。本轮没有向 2GB 服务器安装或部署新解析服务。
- 微信官方虚拟支付与订单查询文档：支付成功由服务端查询核实；道具直购按分计价、按数量结算；普通安卓支付限制与虚拟支付接入不是同一个状态。

没有声称穷尽全球平台，也没有将 AGPL 服务、需要 GPU 的模型或未实测依赖直接放入生产。
