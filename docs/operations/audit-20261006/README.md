## 研究及实现取舍

- [Bolt.new 开源仓库](https://github.com/stackblitz/bolt.new)：参考将需求、文件产物、预览分开的交付模式；使用已有灵犀场 website engine 校验，自行实现，没有引入整个编辑器及重依赖。
- [Haystack SkillToolset](https://docs.haystack.deepset.ai/docs/skilltoolset)：参考把方法指导和真正执行的工具分开；本网站勾选能力必须有对应处理，不能仅改提示词就说已联网或浏览器已操作。
- [LiteLLM 兼容 API](https://docs.litellm.ai/docs/providers/openai_compatible)：地址、密钥、模型独立保存及验证；服务端另加公网地址检查。
- [Tavily Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)：使用真实结果与来源；basic 模式、最多五条，关闭自动升级参数。
- [Google AI 搜索说明](https://developers.google.com/search/docs/appearance/ai-features)及[多语言页面规范](https://developers.google.com/search/docs/specialty/international/localized-versions)：继续做真实可读内容、内链、canonical/hreflang 和与可见页面一致的事实；不承诺加入 GEO 文件就必然收录或增加收入。
- [React 状态保留规范](https://react.dev/learn/preserving-and-resetting-state)：只挂载用户访问过的模式，保留位置与键，避免切换清空输入；未使用要求升级 React 的新接口。[Google 站名规范](https://developers.google.com/search/docs/appearance/site-names)：恢复首页可见品牌及标题，沿用现有 WebSite 标识，搜索显示结果仍由搜索引擎决定。

参考的是经过核对的接口和结构，不复制未经审查的陌生代码。没有新增上述系统的依赖，也没有把两 GB 阿里云服务器改成模型或视频 GPU 工作站。
