## 最新反馈与复核

首页和搜索摘要以 AI 短剧、网站构建开头，删除“一处继续真正重要的工作”等重复口号。九语言网址使用同一首页与页脚，按功能目录由服务器直接输出 116 个已开放工具链接，隐藏两个未开放入口。首页与页脚按用户指定显示“100+免费在线实用工具”，不展示分项免费数量；各付费功能继续在使用前显示真实费用，不更改计费规则。

浏览器与搜索标题改为“AI短剧生成、网站构建、100+免费在线实用工具｜灵犀场 LINGXIFIELD”，九语言对应。正式完整品牌名称仍在首页及页脚；标题避免重复附加 LINGXIFIELD。描述说明 100+ 工具与付费功能，详细名称由目录和功能专页承载，避免把整份工具清单塞进一个过长标题。

搜索引擎会自行选择标题和摘要，更新正文及 metadata 不保证立即改变已有搜索结果；功能专页与链接才是具体问题被发现的基础。参考 [Google 摘要说明](https://developers.google.com/search/docs/appearance/snippet) 和 [Vercel 的错误恢复实现](https://github.com/vercel/ai/blob/main/content/docs/04-ai-sdk-ui/02-chatbot.mdx)，没有复制第三方代码。

完整配置指南补充 Search Console 提交 sitemap 与请求重新抓取的步骤；[Google 官方说明](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl)指出重新抓取可能需要几天到几周，不保证即时收录。普通工具页不能滥用仅适用于招聘/直播页面的 [Indexing API](https://developers.google.com/search/apis/indexing-api/v3/using-api)。

图示短中文网站需求被最少 12 字限制拦截，已改为至少两个字或添加附件；保留空输入与超长输入拒绝。建项目重试复用请求编号，失败不冒充生成成功，错误原因提供九语言下一步提示。生产已补上原有九语言项目迁移：`20261006024831 sasi_project_9lang_release_20261006` 对应 `20260928195500_sasi_project_9lang.sql`。实际项目 RPC 的日文创建和重复请求验证通过，事务已回滚，没有保留测试项目或产生付费调用。

首页需求此前有时在跳转时丢失，SASI 页面也没有消费 `intent`。现在保留需求与语言，识别网站、短剧等任务并填入对应输入框，不会自行提交收费请求；未知需求保留在统一输入框等待用户选择。新增端到端回归覆盖酒店网站需求从首页进入创作，以及失败重试使用相同请求编号。现有生产连接的只读状态核对显示一条 healthy；不读取密钥，也不把该状态当作所有供应商实际生成均成功。

新增 Word 总控文件作为产品目标核对；长视频完整自动制作、自动发布外部网站、独立阿里云执行器和所有第三方账户额度，不能仅凭文档或模拟测试宣称已经完成。用户账户中的真实模型连接仍须供应商授权和额度可用。


## 最新交互调整

SASI 保留现有功能选项，普通对话与图片加入统一输入入口。短剧输入自然语言需求，由服务生成并校验连续镜头，统一报价，明确确认后依次提交，自动查询并按集合成，不再把手写分镜和手动下载后重新上传作为主流程。公开工具目录与页脚全文直接展开。

规划与生成使用真实服务；没有可用连接时提示连接，不提供假成片。付费规划与视频各自明确确认，未知提交状态停止后续提交。分段视频读取只允许当前用户已完成的任务，DNS 固定并阻止内网、限制重定向和每段大小。合成在浏览器完成；关闭页面后供应商任务继续，重新打开项目会恢复查询，最终合成需要页面打开。当前每项最多 60 镜/10 分钟、每集最多 24 镜，不承诺超出范围的长剧。真实付费供应商尚未通过本轮实际扣费验证。
