# 灵犀场小程序 5.7.5：官网钱包唯一充值入口

日期：2026-11-16

## 变更结论

CNY 与 USD 的余额充值统一由灵犀场官网新版钱包处理。小程序中不再存在原生余额充值页面，也不再提供新建原生余额充值订单的 API。

- 官网钱包入口：`/ai-wallet`
- CNY：`/ai-wallet?currency=CNY`，官网收银台使用微信支付或支付宝。
- USD：`/ai-wallet?currency=USD`，官网收银台使用 PayPal。
- 小程序内跳转：`/pages/web/index?path=%2Fai-wallet%3Fcurrency%3DCNY` 或 USD 对应路径。
- 工具商品微信虚拟支付仍由独立工具商品支付页处理。

## 本次彻底移除

- `miniapp/pages/balance/` 全部页面源码、样式和配置。
- `miniapp/pages/recharge/` 全部页面源码和配置。
- `miniapp/utils/topup-expiry.js`。
- `miniapp/utils/virtual-payment-errors.js`。
- `/api/wechat/mini/balance-pay/availability`。
- `/api/wechat/mini/balance-pay/create`。
- 旧充值页面在主小程序及临时邮箱小程序构建器中的路由注册与生成逻辑。
- 旧的 `openMiniRecharge` 跳转函数和 MiniPaymentBoundary 原生充值拦截。

## 保留的能力与数据

- 官网钱包的 CNY/USD 余额、账本、充值、退款、提现和订单记录。
- CNY 官网收银台原有微信支付、支付宝流程。
- USD 官网收银台 PayPal 流程。
- 工具商品独立的微信虚拟支付页面、API、SKU 和订单。
- 已创建的历史原生充值订单回调验签、微信查单、幂等结算逻辑。
- 历史订单、退款记录、余额和资金账本均不删除。

## 账户资料

- 用户名保存按钮使用明确的“保存”文案。
- 移动端保存按钮改为输入框下方全宽布局，避免被容器裁切或显示成黑色残块。

## 真机验收

1. 从小程序首页、账户页、工具余额不足入口分别进入官网钱包。
2. CNY 链接进入新版钱包并默认选择人民币。
3. USD 链接进入新版钱包并默认选择美元，PayPal 收银台可用时继续结算。
4. 小程序包内不存在旧原生余额页及充值缓存文件。
5. 工具商品微信虚拟支付独立可用。
6. 账户用户名输入、保存、刷新后显示正确。
7. 历史订单、退款记录和资金账本正常。
