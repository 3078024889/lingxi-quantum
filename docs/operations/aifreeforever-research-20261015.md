# AiFreeForever 代码与产品研究

## 可核实范围

用户提供的截图是宣传视频与 AI 生成评论，不是源码、许可或可用性证明。搜索覆盖官网说明、GitHub 的同名项目与网站引用，尚未找到可确认为官网全部工具源码的官方仓库，不能声称“700 多项功能已全部开源并可直接复制”。[官网说明](https://aifreeforever.com/about) 的索引内容也使用过不同工具数量，数量与免费承诺均只记为站方宣传，未经本次全量验证。

官网首页与条款地址直接访问返回 403，未进行验证码规避，也没有把抓取失败写成模型功能可用。没有注册、提交用户文件或调用其生成服务。

## 找到的第三方代码

仓库：[lza6/Aifreeforever-2api](https://github.com/lza6/Aifreeforever-2api)，固定提交 `b9bf20a2a77e419d40afed091e77f9202f6726cb`，许可 Apache-2.0。它是将第三方聊天网页转换成兼容聊天 API 的代理，不能当作 AiFreeForever 全站源码或模型权重。

对仓库 8 个 Python 文件建立 AST、文件大小与 SHA-256 清单，检查入口、配置结构、请求转换、SSE、浏览器页面管理、依赖、Docker 和 Nginx。未读取凭据文件，未安装、运行或部署它。完整代码盘点保存在本机 `aifreeforever-source-review.json`。

具体结论：

- 入口只有聊天完成、模型列表和服务说明；没有七百个工具引擎、视频生成、配音或照片修复实现。
- 通过持久化浏览器页面调用站内接口；页面由锁串行复用。它依赖网站页面、服务协议和验证行为，不是稳定官方服务连接。
- 模型查询失败时会回退到静态列表，列表出现模型名不能证明该模型可调用。
- 聊天流等待队列未设置完整任务截止时间；上游 HTTP 或解析失败可以只结束流，缺少可交付结果的严格验证。
- 依赖中 Playwright 固定为 1.44.0，其他多项未固定版本；Nginx 设置一天的读取等待。不能为新系统照搬旧版本、无界等待与第三方挑战处理代码。
- README 要求至少 2 GB 可用内存，且常驻浏览器。用户服务器总内存仅 2 GB，不据此把整套代理强行放进生产服务器。

本次未复制其实现代码，不新增该代理为免费模型供应商，也没有把“开源代理”宣传成“免费无限算力”。

## 已落地的产品优势

借鉴免登录、低门槛和明确分类的产品思路，给现有工具大厅新增“免费本地工具”筛选与“每日免费体验”标记，覆盖九国语言，可通过 `/tools?access=local` 直达。筛选可与搜索、分类叠加。

体验分类同时检查本地处理属性及原有付费目录，不能仅因本地运行就标免费。永久脱敏、手写识别、PDF 转 Word、音频降噪等本地付费导出排除在外；文档翻译体验额度与真实视频服务也不包装为无限免费功能。

既有实际文件处理、错误恢复和输出验证继续完善；没有为增加目录数量制造重复页面或未实现功能。真实智能生成仍复用已有正规服务连接、额度检查和视频异步任务链路，不拿模板动画替代成片。
