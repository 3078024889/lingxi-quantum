# SASI 短剧与网址推广研究补充

核对 [百度搭子开发平台](https://cloud.baidu.com/product-s/dumate_developement_platform.html) 后，可确认其公开介绍包含托管智能体、技能、工作流、权限和运行追踪，并将脚本、配音、字幕作为短剧交付的一部分。这说明可借鉴完整的任务编排思路；不能据产品宣传推断完整实现已开源，或保证任意输入都无需检查。

[Hogee 官方产品页](https://cloud.baidu.com/product/Hogee/aidrama.html) 另外介绍角色与场景控制、分镜规划及多模型调度。上述效果和成本数字属于厂商宣传，本次没有付费生成与独立质量验收，未复制其私有代码，也未提交其联系表单。

对 SASI 的实际要求是：保留输入事实与用户确认，准备人物、场景和连续分镜，复用现有视频服务连接与报价，异步取得真实视频回执，校验可访问的视频结果并保存交付；没有连接和有效回执时明确停止。网址推广不得用模板动画、幻灯片或静态图平移代替真实动态视频。已有三个视频服务适配器的提交、回执和轮询协议使用隔离请求验证，不能把这写成实际成片质量证明。

本次不在用户 2GB ECS 安装常驻浏览器代理或视频大模型。远端构建与测试迁至 GitHub Actions；真实生成的计算由用户连接的服务承担。服务可用性、原生音频能力、人物连续性、字幕与品牌信息的最终质量必须分别验证，不能仅靠取得 MP4 地址断言“完美成片”。

AiFreeForever 已确认的第三方聊天代理与官网完整源码的区别、许可证及本次未采用的部分，见 [代码研究记录](./aifreeforever-research-20261015.md)。没有将第三方聊天代理当成免费图像、配音或视频引擎。
