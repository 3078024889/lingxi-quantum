# SASI 自托管多模态：本次验收记录

基础版本：`6b2b89619ccd76476d0d1512e61cf251de5033e0`。独立分支：`codex/sasi-self-hosted-20260926`。没有覆盖主工作区的未提交文件，没有应用未通过审查的 SASI Planet 包。

## 实现

1. 固定版本的本地文字、视觉、图片、短视频模型加载；运行时禁止自动下载权重。
2. 网页提问入口可携带两张经过本地缩小的图片。按能力检查模型库存、基础推理验收和算力状态；报价和执行两处拦截未就绪能力。
3. 修正带 owner 查询参数的签名不一致问题。请求防重放持久化到 SQLite；支付报价作为幂等请求键，防止重复生成。
4. 修正取消与完成的竞争、工作进程重启后的悬挂状态、数据库连接释放。结果只允许所属用户访问，本地生成文件可直接鉴权下载，无需对象存储。
5. 实测脚本等待最终结果，不再将“已排队”标为推理成功。

## 已执行验证

- TypeScript 全项目检查通过。
- 全站 Next.js 生产构建通过；使用仅指向 `127.0.0.1:9` 的测试 Supabase 配置，无生产数据库连接。存在仓库既有 lint 警告。
- Python 协议测试 8 项通过：库存缺失、签名/重放/用户隔离、幂等冲突、并发领取与取消、重启恢复、下载权限、恶意图片输入、请求大小限制。
- JavaScript 输入测试 9 项通过：文本、图片 URL 拒绝、视频时长边界、JSON 格式、流式体积限制等。
- Python 模块语法检查通过。
- Edge 浏览器：1440px 桌面、390px 手机；图片选择与缩小、视频选项切换、未就绪不出现付款按钮通过；无 pageerror，无手机横向溢出。agent-browser CLI 不可用，因此使用已安装 Playwright 驱动 Edge。
