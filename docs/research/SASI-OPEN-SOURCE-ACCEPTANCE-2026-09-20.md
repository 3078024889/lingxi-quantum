## 产品落实与后续边界

SASI 通用能力由已连接模型提供；SASI 自己负责上下文、角色资料、预算确认、任务状态和结果呈现。连接模型不等于拥有其权重或完成训练。当前通用对话不带联网搜索或代码执行工具，界面明确标注。

长期记忆使用项目隔离的事实、角色和素材索引，按需检索；模型上下文有限，超出上限应摘要或开启新会话，而不是宣称“无限上下文”。本次连续追问使用服务器已保存的本账户历史，超限明确返回。

真正后台整剧仍需要：已开通模型；角色参考能力验收；带全剧预算上限的持久分镜队列；失败只重试明确未提交任务；可持续运行的合成 worker；对象存储、交付与保留期。不能把浏览器本地合成包装成这一整套已上线服务。

当前 Supabase 免费项目实际单文件上限仍为 50MiB。2GiB 是应用可配置上限，不代表云服务已允许。未经实际对象存储接通，不在页面虚标 1GB 可上传。国内对象存储采用按项目一次上传、素材 ID 复用与到期清理；账号和授权凭据尚未提供。
