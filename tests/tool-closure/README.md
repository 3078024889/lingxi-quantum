# LINGXIFIELD Tool Closure
Hard acceptance targets:
- Food: a recognized candidate must either resolve to a calculable entity or explicitly report that no cleared nutrition source is available; never silently disappear.
- Composite fruit salad: search -> composite ID -> manual calculate -> non-empty result, with recipe-estimate provenance.
- ID photo: one input -> preset/background -> exact target pixels -> PNG export. FaceDetector is opportunistic; absence requires manual review, never a false AI-segmentation claim.
- Real portrait/food-image accuracy remains a post-deploy benchmark gate and must not be marked PASS by static tests.
