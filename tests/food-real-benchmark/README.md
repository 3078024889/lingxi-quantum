# LINGXIFIELD Real Food Image Benchmark
Place user-authorized benchmark images outside Git or under a temporary local folder.
Record expected country, expected food/components, and optional known grams in benchmark.json.
Scoring dimensions: detection recall, Top-1/Top-3 identity, component recall, false positives,
confirmation calibration, portion-band accuracy, nutrition continuity and provenance.
No benchmark may mark 100% accuracy from synthetic/static source checks.
