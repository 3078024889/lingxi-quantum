# L5 开拍读库 V1（苍玄 / 短剧开拍强制读 Foundry）

**目的**：影像生产（job create → provider prompt）开拍前必须强制读取 Foundry 身份板 + 连续性（以及 RULE/CONTINUITY/PREFERENCE / 人设类知识），再写入视频 brief。  
**边界**：`trainingEnabled` 保持关闭；空库 / 读库失败 **软失败**（告警日志 + 继续计费视频），不阻断支付与派发。

## 已落地

| 模块 | 路径 | 作用 |
|------|------|------|
| 读库装载 | `lib/sasi/cangxuan/load-series-context.ts` | `loadDirectorFoundryPack` / `assertDirectorFoundryLoaded` / `composeDirectorProductionPrompt` |
| 注入点 | `app/api/sasi/jobs/route.ts` `POST` | 在 `create_and_reserve_sasi_job` 之前读库，拼进 `p_input.prompt`，并附 `foundryPack` 元数据 |
| 时间线 | 复用 `resolveContinuityTimeline`（`lib/sasi/cangxuan-foundry.ts`） | 按角色合并 `state_patch` |

客户端 `CangXuanDirectorStudio` 仍为本地蓝图草稿（无 DB）；**真正发给供应商的 brief** 以 jobs 路由注入为准。

## 读库内容

1. **characters**：`cangxuan_characters.permanent_identity`（可按 `projectId` / `characterKeys` 收窄）
2. **continuity**：上述角色的 `cangxuan_continuity_events`；若传 `episode` 则只取 `episode <= N`，并带 `resolvedState`
3. **knowledge**：优先 `RULE` / `CONTINUITY` / `PREFERENCE`，并抬升人设/身份板类语句；条数封顶

## 请求扩展（可选）

`POST /api/sasi/jobs` body 可附：

```json
{
  "characterKeys": ["LUOYUN", "XIAOWEIBA"],
  "episode": 3
}
```

未传时：取该用户最近更新的角色板（项目优先）+ 相关连续事件 + 高相关知识。

## job.input 字段

- `prompt`：已注入读库块的生产提示词（≤4000）
- `userPrompt`：用户原始提示词
- `foundryPack`：`{ empty, counts, characterKeys, knowledgeIds, … }` 摘要（非整板全文）
- `foundryInjected`：是否成功注入非空包

响应额外返回同结构 `foundryPack`（便于 UI 展示「本镜已读库」）。

## 本地自测

1. Foundry 写入角色身份板 + 连续性事件（`POST /api/sasi/foundry`）。
2. 正常开拍一条短视频 job（登录 + 余额 + Idempotency-Key）。
3. 查 `sasi_jobs.input`：
   - `prompt` 应以「【苍玄·开拍强制读库 / Foundry】」开头（有库时）
   - `foundryPack.empty === false` 且 `foundryInjected === true`
4. 空库用户：job 仍应成功创建；日志可见 `[cangxuan L5] director foundry pack empty`；`foundryInjected === false`。
5. `npx tsc --noEmit` 通过。

## 与 Ask / 双轨关系

- Ask（L4）是问答检索；本 L5 是 **开拍生产 brief** 强制读库。
- 二者同读 `cangxuan_*`，都不打开训练开关。
