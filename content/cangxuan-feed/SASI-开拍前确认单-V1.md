# SASI 开拍前确认单 V1

> 目标链路：交剧本 →（可选）精炼爆款 IP → 确认规格 → 报价确认 → 一键出电影级成片。
> 计费：人民币余额 · 本次报价 · 确认 · 预扣 · 结算（SASI V1）。

## A. 权利与剧本

| 项 | 选项 / 说明 |
|---|---|
| 版权来源 | 自有 / 已购 IP / 客户授权 |
| 剧本策略 | **优化打爆款** / **一字不动按原文**（买了 IP 或合同锁死走后者） |
| 可改范围 | 剧情 / 对白 / 分集结构 / 仅视听（不改故事） |
| 敏感与合规 | 未成年、品牌露出、平台禁区需事先声明 |

## B. 成片规格

| 项 | 选项 / 说明 |
|---|---|
| 形态（苍玄六席） | 漫剧 / 短剧真人 / 电影预演 / 广告 / MV / 游戏 CG |
| 每集秒数 | 自定义，或默认 **90 秒** |
| 集数 | 全剧 / 先试 1–3 集 |
| 画幅 | 竖屏 9:16 / 横屏 16:9 / 方屏 |
| 分辨率与画质档 | 标准 / 电影级（影响报价） |
| 字幕 | 有无、语种；表情字 / 心声轨是否开启 |

## C. 人物与声音

| 项 | 选项 / 说明 |
|---|---|
| 形象 | 指定参考图 / 只给文字锁定 / 交给苍玄定妆 |
| 一致性 | 脸、服、年龄感、道具禁漂（Foundry 身份板强制检索） |
| 配音 | 指定声线或演员 / TTS 风格 / 无对白纯画面 |
| BGM | 指定曲 / 风格包 / 无版权风险曲库 |

## D. 叙事与交付

| 项 | 选项 / 说明 |
|---|---|
| 爽点密度 | 红果式快兑现 / 克制电影感 |
| 旁白 / 心声 / Q 脸 | 开或关 |
| 交付物 | 成片视频 / 分镜脚本 / 角色定妆包 / 可续集圣经 |
| 水印与 AIGC 标识 | 按平台与法规要求 |

## E. 计费（SASI V1）

1. 充值人民币余额  
2. **本次报价** = 时长 × 集数 × 画质档 + 指定资产附加（形象 / 配音 / 超长 / 加急 / 多语字幕等）  
3. 用户确认 → 预扣 → 成片 → 结算  

**规则：** 未完成确认单，不开拍、不扣费。

## F. 养料习惯（对内）

多看热门剧本、小说、爆款短视频；看到喜欢的就记；持续抓「人类喜欢什么」，服务用户心智。公开作品只学抽象结构与节拍，不把他人整本剧本灌进 Foundry。

## G. 多重配音（新增必选）

| 项 | 选项 / 说明 |
|---|---|
| 配音模式 | 多角色分声线 / 单旁白 / 无对白纯画面 |
| 声线指定 | 每角色指定参考音 / 风格标签（软/沉/幼/老） / 交给 SASI 定妆声 |
| 多语 | 普通话默认；可加方言/外语轨（加价） |
| 一致性 | 同角色跨集声纹锁定；禁无故换声 |
| 心声轨 | 与对白分轨或同轨压混；漫剧可开「心声音色」 |
| 交付 | 成片混音 / 干声分轨（可选） |

规则：一键成片默认启用多重配音能力；客户指定声线时写入 Foundry 身份板 `voice_lock`。
