## 如何丢进 Data Foundry

1. 先入库 `00-SERIES-BIBLE.md`（`SCRIPT` + `CONTINUITY`），建立身份板与 promise chain 索引。
2. 按集摄入 `episodes/E##.md`：**全文 beats 保留**，禁止只吃摘要。
3. 解析时按 `00-SCHEMA.md` 映射：
   - 对白 / 心声 / 动作叙事 → `SCRIPT`
   - 镜头指示 → `SHOT`
   - 连续性锁定 / 身份板 → `CONTINUITY`
4. 校验：每集「本集承诺 / 上集回收 / 下集钩子」可检索；E12 应对齐圣经「至第 12 集必须兑现」清单。
