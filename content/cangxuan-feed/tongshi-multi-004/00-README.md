# 全球全科通识增产产线（tongshi-global）

**目标体量（Celestial）**：约 **100 亿** 条全球全科通识。  
**人心库**：必修子集，不是全部体量。  
**求真**：不编假；公开可引用来源；不盗版整本；不碰账密。

## 条目形态（三件套）
每条至少包含：
- `proposition` 命题（可检验的陈述）
- `event_or_context` 事件/语境（何时何地何系统）
- `evidence` 证据要点（可指向来源类型，非伪造链接堆砌）
- `discipline` 学科标签
- `tier` bronze|silver|gold
- `confidence` 0–1
- `source_class` open_encyclopedia|open_data|licensed|teacher_synthetic|user_authorized

## 分级
- **bronze**：海量候选入库
- **silver**：校验/去重后
- **gold**：开拍强检索（人心、导演、付费心智等）

## 现实口径
100 亿靠批处理产线，不靠人工逐条写完。进度用「产线日增量 / 去重后存量」报，禁止虚报完成度。
