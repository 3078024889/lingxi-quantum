【一、首页最显眼的大标题"意识显化系统"，为什么怎么改颜色都没变——
找到了】

这次用无头浏览器直接去查首页 h1 标签实际用的 class，结果发现：
components/LingxiPortal.tsx——也就是整个首页最上面那屏（"意识显化
系统"大标题、下面"显/梦/炼"三张卡片、"进入场域"按钮所在的那个组件
——从头到尾用的都是硬编码的 text-white，压根不是 text-bone。前几版
我在令牌层面（tailwind.config.ts）改了多少轮文字颜色，这个组件都不会
跟着变，因为它根本没有引用那个令牌。这是"字改了好几轮，最显眼的标题
却一直是刺眼白色"这个问题的真正原因，这次直接把这整个组件的文字类名
和内联光晕颜色都换成了跟全站一致的令牌，"显/梦/炼"三张卡片背景也从
白色玻璃换成了 Aurora Crystal Glass 深色玻璃。

【二、Typography System V4——按你最后给的定版方案实现】

CSS 变量原样落地：
--text-primary: #DDE6FF（正文）
--text-heading: #F0E6FF + 横向渐变 linear-gradient(90deg,#E0D4FF,#C8E0FF)
（标题，现在 h1/h2 会显示真正的渐变字，不是纯色）
--text-accent-purple: #D8B8FF / --text-accent-cyan: #A0E0D0（强调）
--text-button: #E0F0FF（按钮）
--text-secondary: #B8C9E6（小字辅助）
--glow-soft: 0 0 8px rgba(224,230,255,0.45)（全站统一光晕）
这些变量写进了 :root，同时 tailwind 里 bone/lattice/amber/violet 这些
令牌全部改成对应色值，两边保持同步。

【四、心声之雨拆成两半：左侧文字，右侧数据】

按你的想法，光点+引言只在左侧窄带出现了（原来是左右都有），每颗光点
绽放的气泡前面也换成了会变化的图标（✦☾♡✎❋◈ 轮流），不再是固定的
"✧"一个符号。右侧新做了一个"场域数据"面板（新组件 FieldStats.tsx），
四行数据从 0 缓缓数到目标值、之后每隔几秒随机跳动一下个位数，视觉上
呼应"数据落下、场域还在活着"的感觉。

**这里必须跟你说清楚**：这四个数字（生命图谱生成数、梦境解析数……）
是装饰性的氛围数字，不是接了真实数据库统计出来的——目前网站没有这类
埋点/统计接口。我在代码里留了注释，以后要换成真实数据，把
FieldStats.tsx 里 STATS 数组的 base 值换成从接口读回来的真实数字即可，
不用动动画逻辑。先说清楚这点，免得你以为这是真实运营数据。
